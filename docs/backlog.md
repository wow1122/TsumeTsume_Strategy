## 宿題（作者と相談すること）

**Stage_01 の手応え**

- 鉄の弓8で、敵弓兵が味方飛行兵を移動しても一撃で倒す
- 敵白翼騎兵 (3,9) が城壁を越えて来る・味方の飛行兵が山を越えて動ける（数値は未調整）

**武器**

- 敵の武器選び（いまは払えなくなったら一番安い武器へ自動で持ち替えるだけ。鋼・銀を持たせる敵には、持ち替え先として鉄の武器も持たせておく）
- 剣の撃破後1マス再移動を敵AIにも使わせるか
- 武器1本のユニットでも一覧を1段通る（作者合意）。プレイしてテンポが悪ければ「押せる武器が1本なら飛ばす」へ変えられる（`EnterWeaponSelect` の分岐1つ）
- 武器を選んだ時点で装備が確定するので、**一覧を開いて右クリックで戻るだけでも装備が変わりうる**（ホバーでは変わらない＝クリックしたときだけ）。
  「攻撃をやめたのに武器が変わっている」と感じるようなら、対象選択のキャンセルで元の武器へ戻す案もある
- 杖（回復）の武器選択は入れていない（杖を2本持つユニットが出たら同じ形で足せる）

**有効と特効**

- 光魔法の武器種由来の特効は当面なし（武器アセット自体が未作成。作るときに一緒に決める）
- 特効が乗ったときの視覚表現（ダメージ数字の色・効果音）は仮素材のままなので将来
- 弓・魔導書の特効が一撃必殺になる件は、原案どおり3倍で入れてある。手応えを見て判断する
- `Stage_EffectiveTest` の説明と数値は当時の11本前提で古い（ステージ自体は動く）

**ゲージ**

- Stage_01 では両ゲージとも発動しない（原案の閾値のまま実装したため）。遊べるようにするなら、ユニットの能力値を上げるか `GaugeRules` の定数を下げる調整が要る
- 必殺技は現状「全兵種共通のダメージ2倍」。兵種ごとに違う必殺技にするなら `ClassData` に効果データを持たせる段階へ進む

**ユニット情報UI**

- **中身が無い枠が4つある**（顔グラフィック・スキル4行・クラスごとの必殺技・兵種経験値バー）。
  実装するときは、表示側は `UnitInfoView` の該当箇所を差し替えるだけで済むようにしてある
- パネルは幅500px・高さ約510px固定（`UnitInfoPanel` の Inspector で幅と行の高さを変えれば追従する）。
  Unity の Game ビューを小さくすると盤面に近づく。窮屈なら幅か行の高さを下げる
- 陣営（自軍／敵軍）と「未行動／行動済み」がパネルに無い。遊んで分かりにくければ戻す
- 持ち物枠は空きスロットぶんも含めて7行、状態枠は3行を常に確保している（高さを一定に保つため）。詰めたければ所持数・行数に合わせて縮める変更ができる
- 敵フェイズ中は画面に状態表示が出ない。分かりにくければ、敵フェイズ中だけの小さな表示を足す

**敵の攻撃範囲の表示**

- 外枠は内側の穴を埋めて描くので、枠の内側に実際には届かないマス（弓兵の死角など）が入ることがある。
  線でも囲みたくなったら「誰も入れない壁の穴だけ埋める」形に変えられる（`GridManager.FillEnclosedWalls` を `SetMarkedZone` の `FillHoles` と差し替えるだけ）

**救出の中継**

- 中継をつなぐと、騎乗3体の行動と引き換えに徒歩1体を24マス先（Stage_01 の盤面の端から端）まで運べる。
  プレイヤー側の拠点到達を勝利条件に入れるときは、中継で一気に運ぶ手が唯一の正解にならないかを見る

**作者所有の文書**

- `docs/コアシステム仕様書.md` と Desktop の仕様書には、飛翔・対空の節や「天馬」「亜竜」の語が残っている
  （作者所有なので Claude は触らない。いまの仕様は `docs/spec/` が新しい）

## 持ち越し候補（次期ロードマップの相談用。優先度は作者が決める）

過去の合意で先送りになった項目のメモ:

- **兵種ごとの必殺技**（いまは全兵種共通のダメージ2倍。`ClassData` に効果データを足して兵種の個性を出す段階。効果の型を数種類作って Stage_01 に出る兵種へ割り当てる案が有力）
- **能力値スケールの見直し**（メモリ・覚醒の閾値が現行の能力値では届かない。育成要素を入れて能力値が20〜30まで伸びれば自然に解決するが、それまでは Stage_01 で発動しない）。
  能力値を上げるときは、回数の制限が無い再行動が雪だるまにならないかも見る（速さ25なら、3連続目以降は2体倒すごとに全員の覚醒が1本ずつ貯まり直す）
- **敵AIのゲージ使用**（蓄積は陣営を区別せず動いているので、`EnemyAI` に評価を足せば使える）
- 輸送隊への預かり（部隊倉庫。相手を「盤上の1体」から「部隊共有の置き場」に差し替えれば同じ交換画面を使い回せる）
- **資源（素材）システム**（第3の所持品。標準装備以外の武器の回復に資源を要求する段階を想定していたが、耐久と補給の撤廃で入口が無くなった。入れるなら作り直し）
- **敵AIの武器選び**（いまの敵は払えなくなったら一番安い武器へ自動で持ち替えるだけ。払える中から強い武器を選ぶ等）
- **剣の撃破後1マス再移動を敵AIにも使わせるか**（当面プレイヤーだけ）
- 勝利条件バリエーション（拠点到達など。Phase 15 と敵AI強化キックオフで2回先送り）。
  **作者の計画: 拠点＝到達地点を置き、飛行兵がそこへひたすら進む挙動を作る**（いまの飛行兵が越えられるのは地形〔山・城壁など〕だけ）。
  プレイヤー側の拠点到達を入れるなら、引き渡しの中継で一気に運ぶ手との兼ね合いを見る
- 救出系コマンドの敵AI使用（現状は「敵は救出系を使わない」合意のまま）
- 敵の性格の追加（挑発後も動かない完全固定砲台型など）
- 敵側の輸送隊・敵の装備切替/道具使用（現状はプレイヤー専用）
- 敵を非武装にするスキル（作者の所持品の仕様書で見送り）
- uGUI化・本番素材への差し替え（IMGUIと色付き四角の置き換え。素材差し替え時期にまとめて）
- 育成要素（レベル・経験値・成長率。ロードマップ外の将来枠）
- 兵種データの残り（クラスチェンジの実行・光魔法の武器アセットと効果・主人公＝軍師ユニットの作成）
- **将来の「竜」ユニット**（竜タグを直接持つ兵種は0体で、枠だけ空けてある。竜には弓の白翼特効も斧の竜騎兵有効も効かないので、
  対抗手段は魔導書・竜特効の武器（ドラゴンキラー・ドラゴンアクス・ドラゴンボウ）・素の火力だけ）
- 新ステージの追加・能力値や配置の調整（アセット編集）は作者の依頼があれば随時
