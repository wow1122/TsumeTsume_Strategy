**ユニット情報UIの宿題（2026-08-16。作者と相談すること）**:
- **中身が無い枠が3つある**（顔グラフィック・スキル4行・クラスごとの必殺技・兵種経験値バー）。
  実装するときは表示側は `UnitInfoView` の該当箇所を差し替えるだけで済むようにしてある
- パネルは**幅500px・高さ約510px固定**（`UnitInfoPanel` の Inspector で幅と行の高さを変えれば追従する）。
  Unity の Game ビューを小さくすると盤面に近づく。窮屈なら幅か行の高さを下げる
  ※**幅をこれ以上狭めるなら状態枠の「ガード：〇（前衛歩兵と隣接）」を先に短くする**（一番きつい行）
- **陣営（自軍／敵軍）と「未行動／行動済み」がパネルから消えた**。遊んで分かりにくければ戻す
- 持ち物枠は空きスロットぶんも含めて7行、状態枠は3行を常に確保している（高さを一定に保つため）。
  詰めたければ所持数・行数に合わせて縮める変更ができる
- 情報が増えたときは**行を足すよりホバー詳細へ逃がす**（1カラム全角15文字の制約があるため）

**武器選択まわりの宿題（作者と相談すること）**:

- 杖（回復）の武器選択は入れていない（杖を2本持つユニットが出たら同じ形で足せる）
