## 撤廃した仕組み

**飛翔・対空・撃墜（2026-10-24 撤廃）**

- 当時の節の全文: `git show a51b575:CLAUDE.md`（「飛翔の合意仕様」「飛翔の活用の合意仕様」「撃墜の合意仕様」）
- **飛翔**（Phase 14）: 飛行兵専用の行動を消費しないコマンド。発動ターンを含めて3ターン持続・着陸コマンド（即行動終了）・地形無視・敵の頭上のすり抜け（飛翔中の敵と対空武器の敵は不可）・
  空中は飛翔中どうしか対空武器とだけ戦える・地形防御なし・段階的な取り消し
- **飛翔の活用**（Phase 20）: 敵AIの離陸・巡航（対空圏の回避）・着陸の判断。probe（お試し飛翔）方式
- **撃墜**（2026-08-05）: 対空武器の攻撃が当たると飛翔が解け、次の自分のターンは飛翔できない
- **対空**: 後衛の攻撃武器と、対空状態を持つ前衛の特効武器（特効の相手にだけ）
- 一緒に消えたもの: `Stage_AITest_Flight`、`StageData.Placement.initialFlightTurns`、`ClassData.flightMove`、`WeaponData.grantsAntiAir`、
  `ActionKind.TakeOff` / `LandAndWait`、`ThreatMap.GetAirThreatCells`、`CombatRules.CanEngage` / `IsAntiAirCapable` / `ShootsDown`、
  `Unit` の飛翔・撃墜の状態、`ActionContext` の飛翔の中間点、武器一覧の「空中不可」、戦闘予測の撃墜の注記
- 拠点へ進む飛行兵の計画は、敵の頭上を越えられなくなったので「地形を越えて進む」に変わった（[backlog.md](backlog.md)）

**武器の耐久と輸送隊の補給（2026-10-24 撤廃）**

- 当時の節の全文: `git show 5fbc7bd:CLAUDE.md`（「武器の耐久と補給の合意仕様」）

## 仕様の変遷

後から見て「なぜ今の形か」が分かりにくいものだけ残す。

- **覚醒の貯まり方**: 初版（2026-07-26）は「2連続目に2回分さかのぼる」、Play 確認後に「2連続目以降、撃破1回につき 速さ÷2」、2026-10-25 にいまの3段階へ
- **再行動の回数**: 旧版は「1ユニットにつき1ターン1回まで」（`Unit.UsedRefreshThisTurn`）。2026-10-25 に作者の指示で外した
- **メモリで払えない武器**: 最初は「装備できない・自動で持ち替える」で実装し、作者が Play で確認した後、
  「いま何を装備しているかを自分の操作の結果にした方がルールを理解しやすい」と見直して、いまの形にした
- **敵の下見**: 2026-10-25 は「1回目のクリックで出し、別のマスのクリック・右クリック/ESC・味方の選択・敵フェイズ開始まで残す」形。
  薄い赤を入れると残った下見が敵の薄い赤を隠すので、2026-10-28 にマウスを乗せている間だけに変えた
- **武器の作り替え（2026-10-24）**: 蜻蛉切・貫きの槍・竜狩りの槍・ポールアクスを削除。竜殺しの剣→ドラゴンキラー、風斬りの剣→風薙ぎの剣、竜狩りの槌→ドラゴンアクス。
  アセットは名前と数値の書き換えで移行し、ファイル名は旧名のまま
- **移動力**: 当初の「標準移動力」（歩兵3・騎兵6・飛行兵6・輸送隊5）の合意は、兵種ごとの値に置き換えた
- **Stage_01 の配布**: 2026-10-26 と 10-28 に作者が持ち物を変更（味方兵・味方騎兵の傷薬を鋼の武器へ、味方弓兵・斧兵・飛行兵に鋼の武器を追加）
