# 兵種の仕様

### 兵種データの合意仕様（2026-07-18 作者合意）

- 兵種は ClassData（ScriptableObject、Assets/_Game/Data/Classes/）で38種を定義:
  下級14職・上級24職。聖騎馬兵は槍兵と騎馬兵の**共有**昇格先でアセットは1つ。
  各兵種 = 名前・階級（下級/上級 ClassTier）・移動タイプ（UnitClass）・移動力・装備可能武器種・
  特攻タグ（ClassTag: 騎馬/白翼/竜/重装/竜騎兵。2026-10-24 に天馬→白翼・亜竜→竜騎兵へ改名）・
  昇格先（下級のみ最大2つ）。兵種表は作者提供（2026-07-18）。
  ※飛翔中の移動力（flightMove。2026-08-10）の欄は 2026-10-24 に飛翔ごと撤廃
- 飛行兵の兵種名（2026-10-24 作者指示）: 天馬兵 → **白翼騎兵**（ファイル Class_SkyKnight）、
  聖天馬兵 → **聖白翼騎兵**（Class_FalconKnight）、金鵄兵（Class_KinshiKnight）は白翼属性のまま、
  竜騎兵は**竜騎兵**のまま（ファイル Class_DragonKnight）、大竜騎兵・魔竜騎兵も名前そのまま。
  同日いったんスカイナイト・聖白翼兵・ドラゴンナイトとしたあと、作者の指示で上の名前に改めた
  （聖白翼騎兵は、下級職の名前に一字足す形＝騎馬兵→聖騎馬兵・竜騎兵→大竜騎兵にそろえたもの）。
  **「竜騎兵」は属性名と下級職の兵種名が同じ**（作者合意。説明では「竜騎兵属性」「兵種の竜騎兵」と書き分ける）。
  兵種ファイル2つは .meta ごと改名した（GUID は不変。ファイル名は最初の改名のときのまま据え置き）。6兵種とも移動6
- 昇格先は**データのみ**（クラスチェンジの実行はレベル/経験値が前提なので将来実装）。
  **特攻タグは 2026-08-06〜08 の「有効と特効」で戦闘に効くようになった**（同節が正）。
  竜騎兵系3兵種（竜騎兵・大竜騎兵・魔竜騎兵）のタグは「竜」から**「竜騎兵」**（旧・亜竜）へ移してある（竜騎兵属性は竜に包含される）
- 昇格で騎乗になる職（聖騎馬兵・鎧騎馬兵・ノマディ・ヴァルキュリア・ダークナイト）は移動タイプ「騎兵」
  → 騎乗の地形ルール・救出可（容量1）・騎馬特攻タグが付く
- 魔法＝魔導＝魔導書は同一武器（WeaponType.Magic）。光魔法は司祭用の別武器種（定義のみ）。
  杖は攻撃できない武器（回復などの効果は将来）
- 武器制限は**警告のみ**（UnitData.OnValidate と Unit.Initialize で Console 警告。動作は止めない）
- 武器側にも兵種の限定を持てる（2026-10-24。WeaponData.exclusiveClasses。長弓は弓聖＝Class_Sniper だけ。
  判定は WeaponMemoryRules.CanEquipByClass＝兵種の装備可能武器と武器側の限定の両方）
- 既存ユニットへの適用（作者合意）: 剣歩兵（味方兵・ダミー2体）は剣闘士（移動3維持。剣士だと移動4のため）。
  武器を兵種に合わせて変更 = 味方飛行兵 剣→槍（天馬兵＝現・白翼騎兵）、斧騎兵2体 斧→槍（騎馬兵。
  名前も味方槍騎兵/敵槍騎兵へ変更。ファイル名 Unit_*_AxeCavalry は GUID 保全のため旧名のまま）。
  敵飛行兵は竜騎兵になり移動力 6→5（ステージ上の敵の到達が変わりうる点は作者了承。
  2026-10-24 から飛行兵6兵種はすべて移動6）

**歩兵の細分化（2026-08-05 作者合意。挙動不変の分類変更）**

- 移動タイプ UnitClass に「重装歩兵」を**末尾に**追加（歩兵0/騎兵1/飛行兵2/輸送隊3/重装歩兵4）。
  この値は .asset に数字で保存されるので、途中に挿入すると既存ユニットの兵種が化ける＝追加は必ず末尾
- **用語**: ゲーム上の呼称は通常歩兵＝「歩兵」で統一。2つをまとめて指す開発用語は「徒歩」。
  コードは IsFoot()（徒歩＝歩兵+重装歩兵）／IsNormalInfantry()（通常歩兵のみ）を使い、
  `== UnitClass.Infantry` の直接比較は書かない（広義か狭義かが読み取れなくなるため）
- 「歩兵」を条件にしていた既存6箇所（救出の対象・引き受けの貨物・代わりに降ろす2箇所・
  挟撃のガード役＝CombatRules.WouldGuardAt と EnemyAI.TryPlanGuard）は**すべて徒歩＝広義**に置換。
  重装歩兵は従来の歩兵とまったく同じ扱い（＝挙動不変。ルール差を付けるかは将来の判断）
- IsMounted() は「歩兵でなければ騎乗」から「**徒歩でなければ騎乗**」（= !IsFoot()）へ変更。
  これで地形（森の騎乗コスト・山の騎乗通行不可）と積載容量0が重装歩兵にも正しく効く
- 特攻タグ ClassTag に「重装」を追加（1<<3・末尾。効果は 2026-08-06 の「有効と特効」で実装済み）。
  移動タイプとは別軸なので、騎兵である鎧騎馬兵にも騎馬＋重装の両方を付けられる
- 移動タイプが重装歩兵の兵種＝重装兵（移動2）・大楯鎧兵（移動2）。
  重装タグを持つ兵種＝重装兵・大楯鎧兵・鎧騎馬兵。
  この3兵種を使っているユニットアセットは現時点で無い（＝プレイ上の変化は起きない）

**マップ上のユニットの絵（2026-10-10 作者要望）**

- マップ上のユニットの絵は**兵種単位**で、ClassData の playerMapSprite（味方用）／enemyMapSprite（敵用）に持たせる
  （陣営で絵の色が違うため2枠）。同じ兵種のユニットはダミーや検証用も含めて全員同じ絵になる
- 未設定の枠は従来どおり**色付きの四角**（味方=青／敵=赤・マスの0.7倍）。行動済みの暗転は絵にも四角にも効く
- 絵は Assets/_Game/Art/Units/ の .aseprite（試運転用・32×32・Aseprite Importer で直接取り込み）。
  Unit.Initialize が**キャンバス32px＝1マス**で拡縮する（定数 MapSpriteCanvasPixels。Aseprite の取り込みは
  透明部分を切り詰めるので sprite.bounds では測らない）。キャンバスが32px以外の絵を足すときはこの定数を見直す
- 割り当て済み（2026-10-10）: 剣闘士・剣士・斧使・槍兵・弓使・魔導士・修道士・騎馬兵・白翼騎兵（旧天馬兵。味方・敵）、
  輸送隊（味方のみ）。竜騎兵・重装兵・鎧騎馬兵などは絵が無く四角のまま
- **新しい絵を取り込んだら必ず Pivot Alignment を Center にする**（Inspector の Layer Import 内 → Apply）。
  既定の Bottom Center のままだと絵が半マス上にずれる。Filter Mode は既定で Point（変更不要）
