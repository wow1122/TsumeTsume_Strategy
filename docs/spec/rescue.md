# 救出・輸送隊の仕様

騎乗ユニットが味方を運ぶ仕組み（救出系コマンド）と、輸送隊の決まり。プレイヤー専用で、敵AIは使わない。

- 可否の判定は `Units/RescueRules` に一元化する（`CombatRules` と同じ方針）
- 再移動の残りと取り消し不能点は `Core/ActionContext`、メニューの組み立ては `BattleController.BuildCommands`
- 確認は Stage_01 でできる

用語: 運んでいるユニットを**運び手**、運ばれているユニットを**貨物**と呼ぶ。
騎乗＝騎兵・飛行兵・輸送隊、徒歩＝歩兵・重装歩兵。運べる数は 輸送隊4・ほかの騎乗1・徒歩0。

## 救出システムの合意仕様

| コマンド | 使える人 | 相手 | 実行した後にできること |
|---|---|---|---|
| 救出 | 空きのある騎乗 | 隣の味方の徒歩（輸送隊は騎乗も） | 再移動 → 待機 |
| 降ろす | 運び手 | 隣の空きマス | 再移動 → 待機 |
| 引き受け | 空きのある騎乗 | 隣の運び手の貨物 | 降ろす／待機（再移動もできる） |
| 代わりに降ろす | 徒歩 | 隣の輸送隊の徒歩の貨物 | なし（行動終了） |
| 引き渡し | 運び手 | 隣の空きのある騎乗 | 再移動 → 待機 |
| 人交換 | 運び手 | 隣の運び手 | 再移動 → 待機 |
| 乗り込む | 輸送隊以外で、貨物を持たないユニット | 隣の空きのある輸送隊 | なし（行動終了） |

再移動＝その行動で使っていない移動力の範囲で動くこと。どのコマンドも、実行した後は攻撃できない。

**救出**

- 行動済みの味方も救出できる（作者合意）
- 運んでいる間のペナルティは無い。前のターンから運んでいるなら攻撃もできる（作者合意）
- 救出と同じ行動では降ろせない（作者合意）

**降ろす**

- 降ろされたユニットは、そのターン行動済みになる（作者合意）
- 降ろした時点では行動を終えず、再移動 → 待機で確定する（作者合意）

**引き受け**

- 引き受けただけでは行動済みにならない
- 「降ろす」を選べるのは、引き受けを実行したマスの上にいるときだけ（作者合意）。
  再移動した先では降ろせず、そのマスへ戻れば また選べる

**代わりに降ろす**

- 貨物が徒歩で「貨物の移動力 ≧ 自分の移動力」のときだけ使える（作者合意）。移動力の低いユニットほど多くの味方を降ろせる、という意図
- 運び手は輸送隊に限る（作者合意）。輸送隊以外の騎乗が運んでいる貨物に手を出せるのは騎乗だけ（＝引き受け）、という整理。
  徒歩は運べる数が0なので、引き受けの判定で自然に外れる
- 輸送隊の行動は消費しない

**引き渡し・人交換**

- 引き渡しは引き受けの逆向き。輸送隊は貨物があっても、空きがあれば受け取れる（作者合意）
- 人交換は貨物を1体ずつ取り替える。お互いに相手の貨物を受け取れるときだけ使える。自分の貨物 → 相手の貨物の順に選ぶ
- どちらも相手の行動を消費しない。行動済みの相手にも渡せる（作者合意）
- 救出・引き受け・降ろすと同じ行動では使えない（作者合意）
- 受け取った味方が未行動なら、そのターンのうちに運んで降ろせる（作者合意）。
  前のターンから運んでいた貨物と同じ扱いなので、中継ができる

中継の距離（平地で、騎乗の移動6・徒歩の移動3のとき）:

- 前のターンから運んでいる貨物は、騎乗1体につき7マス進む（移動6＋隣へ渡すか降ろす1）。2体で14マス、3体で21マス先に降ろせる
- 救出した本人はそのターンに渡せないので、徒歩を救出するところから始めると、徒歩の移動3＋隣1＋騎乗の移動6＝10マス先まで。
  次の騎乗が隣で引き受けて動くたびに+7（17マス・24マス）。ただし、引き受けた後に動いた騎乗はそのターンには降ろせない

**取り消し**

- 救出・引き受け・降ろす・引き渡し・人交換を実行すると取り消せない。選択解除もできず、必ず待機などで行動を終える
  （移動力の使い直しと、相手の状態の巻き戻しを防ぐため）
- 再移動の行き先は、実行した地点まで戻して選び直せる

**盤上での扱い**

- 貨物は盤上から外れる（マスを明け渡す・敵AIの対象にならない・`GetUnits` に出ない）が、生存数（`CountAlive`）には数える。
  「救出中の騎兵＋貨物の徒歩」だけが残っても敗北しない
- 運び手が倒されても貨物は生存する。倒れたマスから近い順に、空きマスへ降ろされる
- 降ろす先は貨物の兵種で判定する（騎乗の貨物は山へ降ろせない。`TileData.IsWalkableFor`）。
  代わりに降ろす・運び手が倒されたときも同じ

## 輸送隊の合意仕様

- 運べる数は4。騎乗（騎兵・飛行兵）も救出できる
- 受け取れる貨物の決まり（引き受け・引き渡し・人交換で共通。`RescueRules.CanReceive`）: 輸送隊は何でも、ほかの騎乗は徒歩だけ
- 誰も輸送隊を救出できない。輸送隊は乗り込みもできない
- 入れ子は禁止: 貨物を持っているユニットは、救出・乗り込みの対象にならない（作者合意）
- 乗り込むと自分は行動終了。輸送隊の行動は消費しない
- 貨物が複数のときは、貨物リスト（`CargoListMenu`）から対象を選ぶ。1体だけなら自動で選ばれ、リストは出ない。
  行にマウスを重ねると、その貨物の情報がユニット情報パネルに出る
- **味方の輸送隊が倒されたら敗北**（貨物の有無は問わない。作者合意）。FE上級者向けに、自由度より機能・挙動を守る方針
- 輸送隊はプレイヤー専用（敵AIが救出系を使わないため。作者合意）
- 輸送隊は武器を持たないので、攻撃コマンドが出ない
