# 救出・輸送隊の仕様

### 救出システムの合意仕様（Phase 11・2026-07-11 作者合意）

- 救出: 騎乗ユニットのみ。対象は隣接する同陣営の徒歩ユニット（騎乗・輸送隊は被救出不可）。
  行動済みの味方も救出できる。救出後は「使っていない移動力分の再移動 → 待機」のみ
- 救出中のペナルティなし。救出中でも攻撃可能。救出と同一行動での「降ろす」は不可
- 降ろす: 隣接する空きマスへ再配置。降ろされたユニットはそのターン行動済み。
  **降ろした後も、使っていない移動力が残っていればその範囲で再移動できる**
  （2026-07-26 作者仕様変更。降ろした時点では行動終了にせず「再移動 → 待機」で確定する。
  攻撃はできない）。
  「代わりに降ろす」は従来どおり、降ろした時点でそのユニットの行動は終了
- 引き受け: 空きのある騎乗ユニットが、隣の救出中の味方から貨物をもらう。
  直後にできるのは「降ろす/待機」のみ（引き受け自体では行動済みにならない）。
  （2026-07-30〜10-24 は飛行兵だけ引き受けの後に「飛翔」「着陸」も使えたが、飛翔ごと撤廃した）
  **引き受けた行動中に「降ろす」を選べるのは、引き受けを実行したマスの上にいるときだけ**
  （2026-07-26 作者仕様変更。引き受け後に再移動した先では降ろせない。
  引き受けたマスへ戻れば また選べる）
- 代わりに降ろす: 徒歩専用。貨物が徒歩で「貨物の移動力 ≧ 自分の移動力」のときのみ。
  **運び手は輸送隊に限る**（2026-07-26 作者仕様変更。輸送隊以外の騎乗ユニットが抱えている貨物に
  干渉できるのは騎乗ユニットだけ＝「引き受け」。徒歩は積載容量0なので引き受けの判定で自動的に除外される）
- **引き渡し**（2026-10-26 作者要望）: 救出中のユニットが、隣の空きのある騎乗の味方へ貨物を渡す（引き受けの逆向き）。
  受け取れる貨物の決まりは引き受けと同じ（通常の騎乗は徒歩だけ・輸送隊は何でも）。
  輸送隊は貨物があっても空きがあれば受け取れる（作者合意）。輸送隊が渡すときは、どの貨物を渡すかを貨物リストで選ぶ
- **人交換**（2026-10-26 作者要望）: 救出中のユニットどうしが、貨物を1体ずつ取り替える。
  自分の貨物 → 相手の貨物の順に選ぶ（1体だけなら自動）。お互いに相手の貨物を受け取れるときだけ使える
- 引き渡し・人交換の共通ルール（作者合意）: **渡した側は「降ろす」と同じく、残りの移動力で再移動 → 待機**（攻撃不可）。
  **相手の行動は消費しない**（行動済みの相手にも渡せる）。**受け取った味方が未行動なら、そのターンのうちに運んで降ろせる**
  （前のターンから運んでいた貨物と同じ扱い＝中継ができる。Stage_01 では徒歩を1ターンで運べる距離が
  最大11マス → 17マス、騎乗をもう1体つなぐごとに+7）。救出・引き受け・降ろすと同じ行動では使えない
  （1回の行動で貨物を動かすのは1回まで）
- 救出・引き受け・降ろす・引き渡し・人交換を実行したら取り消し不能（選択解除も不可。必ず待機等で行動を終える）
- 運び手が倒されたら、貨物はその場（死亡マス）に降ろされて生存
- 格納中のユニットは盤上から除外（占有明け渡し・敵AIの対象外・GetUnits に出ない）が、
  生存数（CountAlive）には数える → 「救出中の騎兵＋格納された徒歩ユニット」だけでも敗北しない
- 可否判定は RescueRules に一元化（CombatRules と同じ方針）

### 輸送隊の合意仕様（Phase 12・2026-07-11 作者合意）

- 輸送隊は容量4。騎乗ユニット（騎兵・飛行兵）も救出・引き受けできる（通常の騎乗兵は徒歩のみ）
- 誰も輸送隊を救出できない。輸送隊自身も他へ格納されない（乗り込みも不可）
- 入れ子救出は禁止：貨物を持っているユニットは救出・乗り込みの対象にならない（合意(a)）
- 乗り込む：輸送隊に隣接した徒歩・騎乗兵が自分から格納される。
  自分は行動終了、輸送隊の行動は消費しない
- 貨物が複数のとき、降ろす・引き受け・代わりに降ろす・引き渡し・人交換は貨物リスト（CargoListMenu）から
  対象を選ぶ。1体だけなら自動選択でリストは出ない。
  リストの行にマウスを重ねるとその貨物の情報がユニット情報パネル（右上）に出る（2026-07-26。下の節）
- 徒歩の「代わりに降ろす」の相手は輸送隊のみ（2026-07-26 作者仕様変更。上の救出の節）
- 引き受けの種別制限：通常の騎乗兵が受け取れるのは徒歩の貨物のみ。輸送隊は何でも受け取れる
  （引き渡し・人交換でも同じ。2026-10-26）
- **味方の輸送隊が倒されたら敗北（ゲームオーバー）**。貨物の有無は問わない。
  FE上級者向けに自由度より機能・挙動を守る方針（作者）。
  通常の騎乗兵の死亡は従来どおり（貨物はその場に降ろされて生存、ゲームは続く）
- 輸送隊は当面プレイヤー専用（敵AIは救出系を使わないため。合意(c)）
- 輸送隊は武器なしユニット（攻撃コマンドが出ない。Phase 9 の非武装の分岐の実地例）

- 降ろす・代わりに降ろす・死亡時解放の配置先も**貨物の兵種**で判定
  （騎乗の貨物は山へ降ろせない。TileData.IsWalkableFor / MoveCostFor が判定窓口）
