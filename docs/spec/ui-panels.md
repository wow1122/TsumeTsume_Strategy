# パネル類の仕様

ユニット情報パネル・戦闘予測・被ダメ確認と、文字の表示幅の制約。

- どれも見るだけのUIで、ゲームの状態は変えない
- いまのUIは IMGUI の暫定実装で、素材差し替えの時期に uGUI で作り直す前提
- パネルはすべて `BattleController` が `AddComponent` で自動生成する（シーンに値は保存されていない）。
  幅を変えたければコードの既定値を書き換えるだけでよい
- 盤面・コマンド一覧・範囲の表示は [ui-board.md](ui-board.md)

## ユニット情報パネルの合意仕様

**置き場所とモード**

- ユニット情報は**画面右上の1枚**（`UI/UnitInfoPanel`）。幅500px
- **常設モード** … 盤上のユニット（敵味方どちらでも）をクリックすると出し続ける。空きマスのクリックで閉じる。
  盤外クリックでは保持。敵フェイズ中・メニュー表示中でも見られる
- **文脈モード** … 相手ユニットを選ぶ場面（救出・引き受け・乗り込む・代わりに降ろす・杖・交換・引き渡し・人交換・攻撃）で
  `BattleController` が `Show` を呼ぶ。作法は戦闘予測と同じ＝選択に入った瞬間から最初の候補を表示し、
  別の候補にマウスを重ねると切り替わる（離れても最後の候補を表示し続ける）。見出しでどのコマンドの相手かが分かる
  （「救出する相手」「引き受ける相手（運び手）」「代わりに降ろす相手（運び手）」「乗り込む先」「杖の対象」
  「交換する相手」「引き渡す相手」「人交換の相手」「攻撃する相手」）
- **貨物リスト（`CargoListMenu`）の行ホバーでも同じ情報を出す**（見出しは「貨物の情報」）。
  貨物は盤上にいないため、文脈モードは「盤面の候補を追うモード」と「指定1体を出す単体モード」の2通りを持つ
- 文脈モードが動いているあいだはそちらが優先。`Hide` で畳むと**常設モードの表示に戻る**（相手選択から戻ってもパネルが真っ白にならない）
- **見出しの行は文脈モードのときだけ**出す。常設モードの見出しは情報として無意味なので消し、中身を上へ詰める
  ＝文脈モードのときだけパネルが1行ぶん高くなる（上端は動かない）
- 戦闘予測は盤上の隅なので、パネルと場所を取り合わない

**レイアウト（左右2カラム。作者仕様書 `Desktop/ユニット情報のUIとレイアウトの改変、新仕様の実装.md`・`UI修正案.md`・`UI修正案2.md`）**

```
| +------------------------+  | 状態 : 前衛                   |
| |                        |  | ガード：〇（前衛歩兵と隣接）    |
| |     顔枠（空欄）         |  | 救出中: 味方弓兵              |
| |   ※残りの高さを全部使う   |  | [スキル]                     |
| +------------------------+  |  ・－  ・－  ・－  ・－        |
| 味方兵          HP 20／20   | [持ち物 3／7]                 |
| 剣闘士        移動力 : 3    |  ・鉄の剣（装備中）            |
| +------------------------+  |  ・傷薬               3／3  |
| | 力   5     守備 5       |  |  ・アーマーキラー       消費4  |
| | 魔力 0     魔防 1       |  |                              |
| | 技   4                 |  |  必殺技: －                   |
| | 速さ 5                  |  |                              |
| +------------------------+  |                              |
| 使用可能武器: 剣・斧          |  メモリ ／ 覚醒のゲージ（最下部）|
| 兵種 ▁▁▁▁▁（経験値バー）     |                              |
```

- 状態・スキル・持ち物は**同時に**縦へ並べる（切り替えは無い）
- **パネルの高さは右カラムで決まり**、左カラムの顔枠が残りの高さを全部もらって下端を揃える
  （`UnitInfoView.ContentHeight`。幅と行の高さから式で出るのでユニットによらず一定）
- **見出しの文言を持つ枠はスキルと持ち物だけ**
- **ステータス枠は中をぴったり二等分**（区切り線は描かない）。左に 力・魔力・技・速さ、同じ行から右に 守備・魔防。
  装備武器はここには出さない（持ち物枠の「（装備中）」で分かる）。
  速さが鋼の武器などで下がっているときは「2(-3)」（下がった後の値＋下がった量）
- 名前／HP・クラス名／移動力・使用可能武器は**枠の外の素の行**。名前とクラス名は左寄せ、HP と「移動力 : x」は右寄せ
- **名前／HP の行だけ文字が一回り大きい**（`NameFontBoost`＝+3px）。下のクラス名／移動力の行とは隙間を詰める（`TextRowGap`＝0）
- **持ち物の行は「左＝品の名前・右端＝数字」**。右端は武器＝メモリ消費「消費5」（消費0は空欄・いまのメモリで払えないときは赤字）／
  道具＝残り回数「残り／最大」。威力・射程などはホバー詳細で見る。
  行の幅がぎりぎりなので、名前は実際の描画幅で測って、入らなければ「…」で丸める（`UnitInfoView.FitText`＝`GUIStyle.CalcSize`）
- 兵種経験値バーは使用可能武器の行の下（左カラムの最下部）。太さはゲージの半分・長さは同じ
- メモリ・覚醒ゲージは右カラムの最下部、必殺技はその上に1行・左寄せ

**状態枠の3行**

1. `状態 : ` ＋ 前衛/後衛（武器が無ければ「非武装」）
2. `ガード：〇（前衛歩兵と隣接）` ／ `ガード：×（前衛歩兵なし）`（`CombatRules.IsPincerNegated`）。
   ×側は列の幅に収めるため、作者合意のうえ短い形
3. `救出中: …`（運んでいるときだけ）

- 行動済みかどうかは出さない（盤上でユニットが暗くなる表現で足りる）
- 格納中の貨物は盤上にいないので、2行目が `格納中（盤上にいない）` に置き換わる（座標も出さない）

**パネルの外の表示**

- **座標** … 地形情報の帯の右端に右詰め（`GridManager.OnGUI`）。帯はカーソルが指しているマスの情報を出す場所なので、そのマスの座標を出す
- **敵AIの性格** … 遊ぶ人には要らないので専用パネルへ（`UI/AIDebugPanel`）。
  ユニット情報パネルが出しているユニット（`UnitInfoPanel.DisplayedUnit`）が敵のときだけ、`敵兵　AI: 待ち伏せ型(未挑発)` の形で1行出す。
  置き場所はユニット情報パネルのすぐ下・右詰め（`PanelRect` から毎フレーム決める。誰の情報かが分かるように作者指示で寄せた）。枠は中身の文字にぴったり合わせる

**ホバー詳細**

- どの項目もマウスを重ねると、その項目の直下に小さな枠が出る。中身があるのは**持ち物の行**だけで、それ以外は1行分の空欄の枠（作者仕様）。
  枠の幅はその列の幅。枠は下の項目に**重なる**（項目を押し下げるとマウスを動かすたびにレイアウトが動いてちらつくため）。下に入りきらない項目では上側へ開く
- 詳細の中身は `UnitInfoLines.BuildItemDetail`＝持ち物メニューのホバー詳細と同じ関数
- パネルの上のクリックは、盤面にも表示中ユニットの切り替えにも使わない（パネル側の `Update` と `BattleController.Update` の両方が `ContainsScreenPoint` で弾く）

**まだ実装が無いもの（置き場所だけ確保）**

- レベル・経験値はコードに存在しない（`ClassTier.cs` に「将来実装」のコメントだけ）。兵種経験値バーは常に空の仮置き
- スキルという概念も存在しない。4行の空欄枠だけ
- 必殺技はユニットごとの名前を持たない（メモリ1本で威力2倍になる汎用機能）。「必殺技: －」の仮表示
- 顔グラフィックは空欄

**その他**

- 表示の文字は `UI/UnitInfoLines`、2カラムの描画は `UI/UnitInfoView` に集約する
- 陣営（自軍／敵軍）はパネルに出さない。盤上の見た目とクリックした文脈で分かる前提で、敵かどうかはパネルの下に AI の行が出ているかでも判別できる
- 持ち物枠は空きスロットも含めて7行ぶん、状態枠も3行ぶん確保する＝ユニットを見比べてもパネルの高さが変わらない

## 戦闘予測

`UI/BattleForecast`。計算は実戦と同じ `DamageCalculator` / `CombatRules` を使うので、表示の数字と実戦の結果は必ず一致する。

- 対象選択に入った瞬間から最初の対象で表示し、別の対象にマウスを重ねるとそちらへ切り替わる（離れても最後の対象を表示し続ける）
- 置き場所は**盤上の4隅のどれか**（作者指示）。「攻撃するユニット自身と選べる相手が乗っている範囲」と地形情報の枠に一番重ならない隅を選ぶ
  （狙う相手がパネルで隠れないように。順番は 左下／右下／左上／右上 で固定）
- **幅220pxの縦長で、行は折り返す**
- 計算式は出さない（作者指示）。**「攻撃力」**（力/魔力＋武器威力）を与ダメージの下、**「防御力」**（守備/魔防＋地形防御）を三すくみの下に出す。
  どちらも三すくみを含まない合計で、読み手は「攻撃力＋三すくみ−防御力＝ダメージ」と足し引きできる（`DamageBreakdown.AttackTotal` / `DefenseTotal`）
- 三すくみは専用の行を必ず出す（補正 ±0 のときも「三すくみ ±0（補正なし）」）
- 行の並び:

  ```
  味方兵 → 敵槍騎兵
  武器: 斬馬刀（消費4）
  メモリ　14 → 10
  与ダメージ　26
  攻撃力　27
  三すくみ +2（有利）
  防御力　3
  （注記の行）
  挟撃 +12（試験・支援・メモリ5）／挟撃はガードで無効（ガード役の名前）
  相手HP 20 → 0　撃破！
  ※剣で倒すと、攻撃の後に1マス再移動できる
  ```

- 注記の行（当てはまるときだけ）:
  - 「※攻撃後、この武器はメモリ不足で使えなくなる」（メモリの行の直後）
  - 「※飛行兵は地形防御を受けない」（防御側の飛行兵が地形防御のあるマスにいるとき）。地形情報の帯にはマスの地形防御が出ているので、数字が合わない理由を見せる
  - 「※マスから動かずに撃つため、三すくみ有利がつく」／「※移動して撃つため、静止撃ちの三すくみ有利なし」（後衛武器）
  - 「※三すくみ逆転（斬馬刀）」
  - 「※特効: 白翼（武器威力3倍）」（[combat.md](combat.md) の有効と特効の節）
  - 必殺技のとき「必殺技 ×2倍（メモリを1本使う。挟撃は等倍）」。見出しは「戦闘予測（必殺技）」で、数字は倍率込み
- メモリの行は必殺技なら1本も込み。払う量が0なら出ない
- 描いた矩形を `PanelRect` で公開する（描かなかったフレームは Rect.zero）。武器の一覧が避けるのに使う

## 被ダメ確認

- 行動メニューに攻撃と同じ条件（攻撃対象がいるとき）で並ぶ。選ぶと閲覧専用の `State.DamageCheck` に入る。行動は消費しない。
  クリックは無視され、ESC/右クリックでメニューへ戻る
- `BattleForecast.ShowIncoming` が「その位置で逆に攻撃されたら」の予測を出す: 被ダメージ・攻撃力・三すくみ（「相手が有利/不利」の表現）・防御力・
  注記・自分の残りHP（「倒される！」の警告）・「※相手の位置どり・挟撃の追加は含まない」
- 敵が動くかは事前に確定できないので、相手が後衛武器のときだけ「移動時／静止時」の2行＋三すくみの両方の値＋HPの両方の結果を並べる（`DrawIncomingBothCases`）
- 相手が非武装なら「この相手は非武装のため攻撃してこない」だけを出す

## 表示幅の制約

実際に見切れたことがあるので必ず守る。

- ユニット情報パネル（`UnitInfoPanel`）… 幅500px・余白10px。**左右2カラム**なので1カラムは234px・枠の中は222px＝**1行15文字が上限**。
  一番きついのは状態枠の「ガード：〇（前衛歩兵と隣接）」（14文字・196px）。**これ以上狭めるならまずこの文言を短くすること**
- ステータス枠の中の左右（能力値）… 111px ずつ＝**全角7文字が上限**
- 持ち物の行 … 右端は武器のメモリ消費「消費N」（約36px）／道具の「3／3」（約28px）＋隙間6px。
  武器の行で名前に使えるのは約180px。**ここだけ文字数の見積もりではなく実測（`UnitInfoView.FitText`）で丸める**。
  名前の長い6本（アーマーキラー・ドラゴンキラー・ソニックソード・フレイムランス・ドラゴンアクス・シャイニングボウ）は
  装備中だと「・アーマーキラー（装…」のように丸められる（作者了承）。全部入れるならパネルを約520〜550pxに広げる
- ユニット情報のホバー詳細 … その列の幅（234px）。中身は持ち物メニューと同じなので、**220px の持ち物メニュー側に合わせて全角14文字**で書く
- 持ち物のホバー詳細（`ItemListMenu`）… 幅220px・余白6px＝208px＝**全角14文字が上限**
- 持ち物リストのボタン … **幅264px**・文字16px＝**全角15文字が上限**（最長は「シャイニングボウ（メモリ不足）」15文字）
- 交換の列の見出し … `ItemListMenu.buttonWidth`（264px）・文字13px。注記は「装備:」の行に足さず別の行にする
- 長い情報は**行を増やさずホバー詳細へ逃がす**。持ち物の行は名前と右端の数字だけにし、種類・威力・射程・メモリ消費・特効・特性は詳細で見せる。
  それでも溢れうる文字列は `UnitInfoLines.Truncate` で「…」に切る
- 戦闘予測（`BattleForecast`）… **幅220px・余白8px＝204px**。**ここだけ行を折り返す**（`wordWrap` ＋ `CalcHeight`）＝
  幅を詰めても注記が消えない代わりに、長い注記は2〜3行になる。高さは中身しだいで決まる
- ユニット情報パネルの高さは幅と行の高さから式で決まる（`UnitInfoView.ContentHeight`）
