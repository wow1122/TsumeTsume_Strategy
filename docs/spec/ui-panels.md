# パネル類の仕様

- 戦闘予測（BattleForecast・IMGUI。※2026-08-17 に盤上の4隅へ）: 対象選択中に攻撃対象へマウスを重ねると
  ダメージ内訳・挟撃の追加ダメージ（またはガードで無効）・相手の残りHP見込み・撃破を表示。
  実戦と同じ DamageCalculator / CombatRules を使うので数値は必ず一致する
  →（2026-07-18 のUI改良で「対象選択に入った瞬間の即表示＋三すくみ専用行」へ更新。
  「デバッグ/テスト用UI」の節が正）
### デバッグ/テスト用UI（2026-07-18 作者依頼。統合調整の補助として追加）

- ① ユニット情報パネル（旧 UI/DebugUnitPanel・画面右上）: 盤上のユニット（敵味方どちらでも）を
  クリックすると能力値・武器・状態を表示。空きマスのクリックで閉じる・盤外クリックでは保持・
  敵フェイズ中やメニュー表示中でも確認できる・ゲームの状態は一切変えない。
  → **2026-08-16 に UI/UnitInfoPanel へ統合され、DebugUnitPanel は削除**。
  上の挙動（クリックで開く・空きマスで閉じる・敵フェイズ中も見られる）はそのまま引き継いでいる。
  「ガードで挟撃を無効化されている」は状態枠の「ガード：〇／×」の行として吸収。
  デバッグ専用だった「AI: 突撃型／待ち伏せ型」は同日の修正案で**専用の UI/AIDebugPanel** へ移し、
  「誰かの挟撃ガード役になっている」の行は削除された。
  詳しくは「ユニット情報パネルの合意仕様」の節
- ② 戦闘予測の改良: 対象選択に入った瞬間に即表示（従来のマウスオーバー待ちを廃止）＋
  三すくみ補正の専用行（補正 ±0 のときも「三すくみ ±0（補正なし）」と必ず表示）
- ④ 被ダメ確認コマンド: 行動メニューに攻撃と同じ条件（攻撃対象がいるとき）で並ぶ。
  選ぶと閲覧専用の State.DamageCheck に入り、BattleForecast.ShowIncoming が
  「その位置で逆に攻撃されたら」の予測を表示（受けるダメージの内訳・三すくみは
  「相手が有利/不利」の表現・自分の残りHP見込みと「倒される！」警告・
  「単発のみ・挟撃含まず」の注記）。クリックは無視され、ESC/右クリックでメニューへ戻る。
  行動は消費しない

### ユニット情報パネルの合意仕様（2026-07-26 作者要望・2026-08-16 に2カラム化で全面刷新）

**置き場所とモード**

- ユニット情報は**画面右上の1枚**（UI/UnitInfoPanel。BattleController が自動生成）。幅500px。
  2026-08-16 に、それまで別々だった右上のデバッグ用パネルと右下の対象選択用パネルを統合した
- **常設モード** … 盤上のユニット（敵味方どちらでも）をクリックすると出し続ける。空きマスのクリックで閉じる。
  盤外クリックでは保持。敵フェイズ中・メニュー表示中でも見られる（旧デバッグ用パネルの挙動をそのまま引き継ぎ）
- **文脈モード** … 相手ユニットを選ぶ場面（救出・引き受け・乗り込む・代わりに降ろす・杖・交換・攻撃）で
  BattleController が Show を呼ぶ。作法は戦闘予測と同じ＝選択に入った瞬間から最初の候補を表示し、
  別の候補にマウスを重ねると切り替わる（離れても最後の候補を表示し続ける）。見出しでどのコマンドの相手かが分かる
  （「救出する相手」「引き受ける相手（運び手）」「代わりに降ろす相手（運び手）」「乗り込む先」「杖の対象」
  「交換する相手」「攻撃する相手」）
- **貨物リスト（CargoListMenu）の行ホバーでも同じ情報を出す**（見出しは「貨物の情報」）。
  貨物は盤上にいないため、文脈モードは「盤面の候補を追うモード」と「指定1体を出す単体モード」の2通りを持つ
- 文脈モードが動いているあいだはそちらが優先。Hide で畳むと**常設モードの表示に戻る**
  （＝相手選択から戻ってもパネルが真っ白にならない）
- **見出しの行は文脈モードのときだけ**出す（2026-08-16 の修正案）。常設モードの「ユニット情報」という
  文言は情報として無意味なので消し、中身を上へ詰める。「攻撃する相手」などはどのコマンドの相手を
  選んでいるかを示すので残す＝**文脈モードのときだけパネルが1行ぶん高くなる**（上端は動かない）
- 戦闘予測は盤上の隅なので**場所を取り合わない**（2026-08-09 の「縦積み」は不要になり撤去。
  戦闘予測は 2026-08-16 に右下→盤面の下、08-17 に盤上の4隅へ移った）

**レイアウト（左右2カラム。作者仕様書 2026-08-16 ＋ 同日の修正案・修正案2）**

```
| +------------------------+  | 状態 : 前衛・地上              |
| |                        |  | ガード：〇（前衛歩兵と隣接）    |
| |     顔枠（空欄）         |  | 救出中: 味方弓兵              |
| |   ※残りの高さを全部使う   |  | [スキル]                     |
| +------------------------+  |  ・－  ・－  ・－  ・－        |
| 味方兵          HP 20／20   | [持ち物 3／7]                 |
| 剣闘士        移動力 : 3    |  ・鉄の剣（装備中）            |
| +------------------------+  |  ・傷薬               3／3  |
| | 力   5     守備 5       |  |  ・アーマーキラー       消費4  |
| | 魔力 0     魔防 1       |  |                              |
| | 技   4                 |  |  必殺技: －                   |
| | 速さ 5                  |  |                              |
| +------------------------+  |                              |
| 使用可能武器: 剣・斧          |  メモリ ／ 覚醒のゲージ（最下部）|
| 兵種 ▁▁▁▁▁（経験値バー）     |                              |
```

- **レイアウトの切り替えは無い**（初版の「状態＋スキル／持ち物」をクリックで切り替える案は
  2026-08-16 の修正案で廃止）。状態・スキル・持ち物を**同時に**縦へ並べる
- **パネルの高さは右カラムで決まり**、左カラムの顔枠が残りの高さを全部もらって下端を揃える
  （`UnitInfoView.ContentHeight`。幅と行の高さから式で出るのでユニットによらず一定）
- **見出しの文言を持つ枠はスキルと持ち物だけ**。「ステータス」「自軍／敵軍」「状態」は
  修正案で削除したので、その枠は枠線だけになり中身が1行ぶん上へ詰まる
- **ステータス枠は中をぴったり二等分**（区切り線は描かない）。左に 力・魔力・技・速さ、
  **同じ行から**右に 守備・魔防。**装備武器はここには出さない**（修正案2で削除。
  何を装備しているかは持ち物枠の「（装備中）」で分かる）。
  速さが鋼の武器などで下がっているときは「2(-3)」（下がった後の値＋下がった量。2026-10-24）
- 名前／HP・クラス名／移動力・使用可能武器は**枠の外の素の行**。名前とクラス名は左寄せ、
  HP と「移動力 : x」は右寄せ。Lv の表示は修正案で削除
- **名前／HP の行だけ文字が一回り大きい**（`NameFontBoost` ＝ +3px）。
  この行と下のクラス名／移動力の行は**隙間を詰めて**（`TextRowGap` ＝ 0）ひとまとまりに見せる（修正案2）
- **持ち物の行は「左＝品の名前・右端＝数字」**（修正案2。当時の右端は武器の耐久値『残り／最大』）。
  2026-10-24 から右端は **武器＝メモリ消費「消費5」（消費0の武器は空欄・いまのメモリで払えないときは赤字）／
  道具＝残り回数「残り／最大」**。威力・射程などはホバー詳細で見る。
  行の幅がぎりぎりなので、名前は**実際の描画幅で測って**入らなければ「…」で丸める
  （`UnitInfoView.FitText`＝`GUIStyle.CalcSize`。文字数から見積もる `Truncate` と違い絶対に重ならない）
- **兵種経験値バーは使用可能武器の行の下**（左カラムの最下部）。太さはゲージの半分・長さは同じ
  （左右のカラム幅を等しくしてあるので `GaugeBars` の定数がそのまま効いて長さが揃う）
- メモリ・覚醒ゲージは右カラムの最下部、必殺技はその上に1行・左寄せ

**状態枠の3行（修正案で5行から絞った）**

1. `状態 : ` ＋ 前衛/後衛（武器が無ければ「非武装」）。以前は「・地上/飛翔」「・陣中/孤立」も続いたが、2026-10-24 に飛翔・補給ごと撤廃
2. `ガード：〇（前衛歩兵と隣接）` ／ `ガード：×（前衛歩兵なし）`（`CombatRules.IsPincerNegated`）。
   ×側は列の幅に収めるため作者合意のうえ「隣接した」を省いた短い形
3. `救出中: …`（運んでいるときだけ）
- 削除したのは「隣接した味方をガード中／ガードしていない」「未行動／行動済み」。
  行動済みは**盤上でユニットが暗くなる既存表現**で足りるという判断
- 格納中の貨物は盤上にいないので、2行目が `格納中（盤上にいない）` に置き換わる（座標も出さない）

**パネルの外へ移した表示**

- **座標** … **地形情報の帯の右端に右詰め**（`GridManager.OnGUI`）。帯はカーソルが指しているマスの
  情報を出す場所なので、**そのマスの座標**を出す＝ユニットにカーソルを合わせればそのユニットの座標になる
- **敵AIの性格** … 遊ぶ人には要らないので**専用パネル**へ（`UI/AIDebugPanel`）。
  ユニット情報パネルが出しているユニット（`UnitInfoPanel.DisplayedUnit`）が敵のときだけ、
  `敵兵　AI: 待ち伏せ型(未挑発)` の形で1行出す。
  置き場所は**ユニット情報パネルのすぐ下・右詰め**（`UnitInfoPanel.PanelRect` から毎フレーム決める。
  当初は画面左下だったが、誰の情報かが離れて分かりにくいので作者指示で寄せた）。
  枠は中身の文字にぴったり合わせる

**ホバー詳細**

- **どの項目もマウスを重ねると、その項目の直下に小さな枠が出る**。中身があるのは
  **持ち物の行**だけで、それ以外は**1行分の空欄の枠**（作者仕様。修正案2でステータス枠から
  武器が消えたので、装備武器の性能もこの持ち物の行から見る）。
  枠の幅は**その列の幅**。枠は下の項目に**重なる**（項目を押し下げるとマウスを動かすたびに
  レイアウトが動いてちらつくため、この形で合意）。下に入りきらない項目では上側へ開く
- 詳細の中身は `UnitInfoLines.BuildItemDetail`＝**持ち物メニューのホバー詳細と同じ関数**
- パネルの上のクリックは**盤面にも表示中ユニットの切り替えにも使わない**
  （パネル側の `Update` と `BattleController.Update` の両方が `ContainsScreenPoint` で弾く）

**まだ実装が無いもの（置き場所だけ確保した）**

- **レベル・経験値はコードに存在しない**（`ClassTier.cs` に「将来実装」のコメントだけ）。
  兵種経験値バー（常に空）は表示だけの仮置き。**Lv の表示は 2026-08-16 の修正案で消した**
- **スキルという概念も存在しない**。4行の空欄枠だけ
- **必殺技はユニットごとの名前を持たない**（メモリ1本で威力2倍になる汎用機能）。「必殺技: －」の仮表示。
  クラスごとの必殺技は後日実装

**その他**

- 表示の文字は UI/UnitInfoLines、2カラムの描画は UI/UnitInfoView に集約する
  （格納中の貨物は座標を出さない・盤上にいないのでガードの行は「格納中」に置き換わる）
- **陣営（自軍／敵軍）はパネルに出さない**（修正案で削除）。盤上の見た目とクリックした文脈で分かる前提で、
  敵かどうかはパネルの下に AI の行が出ているかでも判別できる
- 持ち物枠は空きスロットも含めて**7行ぶん確保**、状態枠も**3行ぶん確保**する
  ＝ユニットを見比べてもパネルの高さが変わらない
- 見るだけのUIでゲームの状態は一切変えない。素材差し替え時期に uGUI で作り直す前提の暫定UI

### 表示幅の制約（2026-08-03 と 08-05 に実際に見切れたので必ず守る）

※もとは「武器の耐久と補給の合意仕様」の節の中にあった（耐久を 2026-10-24 に撤廃したので独立させた）。

- ユニット情報パネル（`UnitInfoPanel`）… 幅500px・余白10px。**左右2カラム**なので
  1カラムは234px・枠の中は222px＝**1行15文字が上限**
  （2026-08-16 に 340px の1カラム → 520px の2カラム → 修正案で 480px → 持ち物の耐久値が
  入らず 500px へ戻した）。
  一番きついのは状態枠の「ガード：〇（前衛歩兵と隣接）」（14文字・196px）。
  **これ以上狭めるならまずこの文言を短くすること**
- ステータス枠の中の左右（能力値）… 111px ずつ＝**全角7文字が上限**（「速さ 5」で十分収まる。
  速さが下がっているときの「2(-3)」も収まる）
- 持ち物の行 … 右端は武器のメモリ消費「消費N」（約36px。払えないときは赤字）／道具の「3／3」（約28px）＋隙間6px。
  武器の行で名前に使えるのは約180px。**ここだけ文字数の見積もりではなく実測（`UnitInfoView.FitText` → `GUIStyle.CalcSize`）で丸める**。
  名前の長い6本（アーマーキラー・ドラゴンキラー・ソニックソード・フレイムランス・ドラゴンアクス・シャイニングボウ）は
  装備中だと「・アーマーキラー（装…」のように丸められる（2026-10-24 に作者了承・パネル幅は500pxのまま）。
  全部入れるならパネルを約520〜550pxに広げる
- ユニット情報のホバー詳細 … **その列の幅**（234px）。中身は持ち物メニューと同じ
  `UnitInfoLines.BuildItemDetail` なので、**220px の持ち物メニュー側に合わせて全角14文字**で書く
- 持ち物のホバー詳細（`ItemListMenu`）… 幅220px・余白6px＝208px＝**全角14文字が上限**
  （2026-10-24 に足した行「メモリ消費: 9」「三すくみ逆転: 槍の騎馬」「装備中: 速さ−移動力」などは最長でも11文字）
- 持ち物リストのボタン … **幅264px**・文字16px＝**全角15文字が上限**
  （2026-08-08 に 170→210px、2026-10-24 に 210→264px。最長の「シャイニングボウ（メモリ不足）」
  「シャイニングボウ（届く敵なし）」15文字に合わせた）
- 交換の列の見出し … `ItemListMenu.buttonWidth`（264px）・文字13px。注記は「装備:」の行に足さず別の行にする
- 長い情報は**行を増やさずホバー詳細へ逃がす**のが 2026-08-16 以降の方針
  （持ち物の行は名前と右端の数字だけにし、種類・威力・射程・メモリ消費・特効・装備付与は詳細で見せる）。
  それでも溢れうる文字列は `UnitInfoLines.Truncate` で「…」に切る（品の名前・救出中の相手の名前など）
- 戦闘予測（`BattleForecast`）… **幅220px・余白8px＝204px の縦長**（2026-08-17。
  430px → 540px（計算式の2列）→ **計算式を廃止して 220px** と動いた）。
  **ここだけ行を折り返す**（`wordWrap` ＋ `CalcHeight` で行ごとに高さを測る）＝
  幅を詰めても注記が消えない代わりに、長い注記は2〜3行になる。高さは中身しだいで決まる
- これらのパネルは全て `AddComponent` で作られる（シーンに値は保存されていない）ので、
  幅を変えたければコードの既定値を書き換えるだけでよい。
  ユニット情報パネルの**高さは幅と行の高さから式で決まる**（`UnitInfoView.ContentHeight`）
