# 移動・地形・飛行兵の仕様

### 地形の合意仕様（Phase 13・2026-07-11 作者合意）

- 地形は5種: 平地`.`（コスト1/防御+0）、森`F`（2/+1）、山`M`（3/+2）、砦`T`（1/+3）、壁`#`（通行不可）。
  数値・色は TerrainTable.asset の編集だけで調整できる（記号は terrainRows で使う1文字）
- 地形コストは当面全兵種共通 →（Phase 15 で兵種別コスト・通行制限を導入。「Phase 15 の合意仕様」の節が正）
- 兵種限定の通行制限（山は徒歩のみ等）は当面なし →（同上。Phase 15 で導入済み）
- 地形防御は物理・魔法の両方に加算（Phase 8 合意の継続。DamageBreakdown の「地形」項）
- ステージの地形は StageData の文字マップ terrainRows（リスト先頭=盤面の最上段の行）。
  行数・文字数の不一致や未知の記号は警告して平地扱い
- 地形の適用は BattleSetup.Start → GridManager.ApplyTerrain の流れ（シーン参照の追加は不要）
- 表示は地形色×市松の明暗（GridManager.checkerDarken）。ハイライトは Color.Lerp で
  地形色に混ぜる（highlightBlend）ので地形とハイライトが同時に判別できる。
  カーソル下マスの地形名/コスト/防御と座標を、盤面の真下の帯に1行表示（IMGUI。※2026-08-17 の形）
- 移動範囲計算はダイクストラ法（コスト差のある地形で最短経路を保証）。
  マス進入コストは MovementCalculator.GetMoveCost(unit, tile)。兵種ごとの決まりは
  TileData.MoveCostFor / IsWalkableFor に一本化（飛行兵は常にコスト1・屋内の壁だけ不可。2026-10-24）

### 飛行兵の合意仕様（2026-10-24 作者指示。飛翔・対空の撤廃後の形）

- 飛行兵（移動タイプ UnitClass.Flier）は兵種として残す。6兵種:
  - **白翼属性**: 白翼騎兵（下級。旧・天馬兵）→ 聖白翼騎兵（旧・聖天馬兵）・金鵄兵
  - **竜騎兵属性**（竜属性に含まれる）: 竜騎兵（下級。属性名と同じ名前）→ 大竜騎兵・魔竜騎兵
- **常に飛んで移動する**: 地形に関係なく全マスの移動コストが1。森・山・砦・城壁 `=` も通れて止まれる。
  屋内の壁 `#` だけは入れない（TerrainDef.canFlyOver）。判定は TileData.IsWalkableFor / MoveCostFor の先頭
  （UnitClass.IsFlier()）に一本化してあり、移動範囲・敵AIの距離マップ・配置・降ろす先・死亡時の解放先が
  すべて同じ決まりを見る。騎兵・輸送隊向けの地形ルール（森3・山は通れない）は飛行兵には効かない
- **敵の頭上は通れない**（ほかの兵種と同じ。味方のマスは通過できるが止まれない）
- **誰とでも戦える**: 空中だけの戦闘制限は無い＝近接でも飛行兵を攻撃でき、飛行兵も地上の敵を攻撃できる。
  挟撃・ガードも普通に働く（飛行兵も隣の前衛徒歩ユニットに守られる）。救出（容量1）・引き受け・交換・杖も従来どおり
- **地形防御を受けない**（DamageCalculator。敵AIのマス選びの TileDefense も0として扱う）。
  戦闘予測には、飛行兵が地形防御のあるマスにいるときだけ「※飛行兵は地形防御を受けない」を出す
  （地形情報の帯にはそのマスの地形防御が出ているので、数字が合わない理由を見せる）
- **移動力は6兵種すべて6**（地上/飛翔の2本立ては廃止）。鋼の武器の「速さ−移動力」は飛行兵だと −6
- 弱点は属性で決まる（「有効と特効の合意仕様」の節）: 白翼＝弓の特効・槍の有効／
  竜騎兵＝魔導書と竜特効の武器の特効・斧の有効
- 城壁 `=` は「地上は通れない・飛行兵は通れて止まれる」。地形防御+2 の値は残るが受けるユニットはいない
  （地形情報の帯にも「城壁　通行不可（飛行兵は可）」とだけ出す）
- 敵AI: ほかの敵と同じ攻撃探索・接近で動く（飛翔の判断は撤廃）。距離マップが飛行兵の地形の扱いをそのまま反映するので、
  Stage_01 の城内の敵白翼騎兵 (3,9) は城壁を越えて南へ来る
- 表示: ユニット情報の状態は「前衛/後衛」だけ、移動力は数字1つ
- 数値（Stage_01）: 敵弓兵→味方白翼騎兵 27（静止29）＝一撃／味方弓兵→敵白翼騎兵 28／
  味方斧兵→敵白翼騎兵 13／味方槍騎兵→敵白翼騎兵 17（槍の白翼有効）
- 作者の設計意図（2026-08-05）の「飛行兵が敵を飛び越えて拠点へひたすら進む」は、敵の頭上を越えられなくなったので
  「地形（山・城壁）を越えて拠点へ進む」に変わる（拠点到達は未実装）

- 兵種別地形（通行制限まで導入）: 騎兵・輸送隊は
  森コスト3（徒歩2）、山は**通行不可**（徒歩のみ）。TerrainDef の mountedWalkable / mountedCost
  （0=共通コストと同じ）で地形ごとに調整できる。飛行兵は地形を無視して全マスコスト1
  （当時は地上の飛行兵もこの騎乗ルールだった。2026-10-24 から常に飛ぶ＝「飛行兵の合意仕様」の節）
