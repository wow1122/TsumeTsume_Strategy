# 盤面と画面の表示の仕様

操作の流れ、マスのハイライト、範囲の表示、コマンド一覧、画面レイアウト、盤上の表示、敵の攻撃範囲の表示。

- 操作の司令塔は `Core/BattleController`（状態機械）。盤面の描画は `Grid/GridManager`
- 見るだけの表示はゲームの状態を変えない
- パネル類は [ui-panels.md](ui-panels.md)
- 入力は新 Input System のみ（`activeInputHandler=1`）。クリックは `Mouse.current` を使う

## 操作の流れ

- 移動 → 行動メニュー（攻撃・被ダメ確認・待機。状況に応じて救出系・持ち物・交換なども並ぶ）→ 対象選択 の FE 型
- キャンセルは右クリック/ESC で1段階ずつ戻る（対象選択 → メニュー → 移動取り消し → 選択解除）
- 移動の取り消しは `ActionContext.RevertMove`（占有も復元する）
- 待機はメニューから明示的に選ぶ
- メニューはユニットの右隣に出し、画面の右端では左へ回り込む
- 盤上のメニュー（行動メニュー／コマンド一覧・持ち物／交換／武器選択・貨物リスト）は**盤面の外に出さない**（`UI/MenuPlacement`）。
  回り込み・押し込みの基準は盤面の矩形で、これで地形情報の帯や右側のパネルと重ならない
- 移動範囲の表示の入口 `ShowMoveRange` は行動メニューを必ず閉じる。
  メニューの項目からそのまま移動選択へ戻るコマンドで閉じ忘れると、前のメニューが残って押せてしまうため

## マスのハイライト

- `HighlightKind` の優先度付き多層管理: Selection（黄）＞ TargetChoice（赤）＞ AttackRange（橙）＞ HealRange（緑）＞ MoveRange（青）＞ 地形の色
- 色の設定は `GridManager` に集約する。色は `Color.Lerp` で地形色に混ぜる（`highlightBlend`）ので、地形とハイライトを同時に見分けられる
- 表示は 地形色×市松の明暗（`GridManager.checkerDarken`）
- `attackRangeColor` のスクリプト既定値は赤 (1, 0.5, 0.5) だが、シーンの値は橙 (1, 0.7, 0.5) のままで、作者がテストして承認している
  （変える場合は `GridManager` の Inspector で色を変えて Ctrl+S → シーンをコミット）
- **移動力の範囲（MoveRange）には、仲間がいて通り抜けるだけのマスも含める**＝赤・緑にしない（作者要望）。
  味方の選択・救出などの後の再移動・敵の下見で共通で、杖ユニットと敵の下見も同じ（作者合意）。止まれるマスの判定は変わらない
- 敵の攻撃範囲の赤紫（Rキー）と紫の外枠、印を付けた敵の薄い赤と外枠は、ハイライトとは別の層

## 範囲の表示

- 自軍ユニットを選ぶと、移動範囲（青）の外周に「攻撃だけ届くマス」を重ねて表示する（`BattleController.ComputeAttackCells`）。
  壁は除く。救出・引き受け・降ろす・引き渡し・人交換の後は表示しない
- 杖ユニットは攻撃の範囲の代わりに、杖が届くマスを緑で出す（[items.md](items.md)）
- 敵の移動＋攻撃の範囲の下見は、印の付いた敵にマウスを乗せている間だけ出る（下の「敵の攻撃範囲の表示」の節）

## 地形情報の帯

- カーソル下のマスの情報を**盤面の真下の帯**に1行で出す（`GridManager.OnGUI`）。**横幅は盤面と同じ・高さは1行で固定**で、位置は動かない。
  作者が 帯 → カーソル追従 → 盤上の4隅 と試し、「位置が入れ替わりすぎて注意力を奪う」としてこの形に決めた
- 左詰めで 地形名・移動コスト（騎兵との差も）・地形防御、右端に座標
- 通れない地形は「城壁　通行不可（飛行兵は可）」のように出す
- 帯の高さは36px。画面の下に空けた10%がその置き場なので、`boardBottomArea` を下げすぎると帯が画面からはみ出す

## コマンド一覧と画面レイアウトの合意仕様

**ねらい**: 画面の隅に貼り足してきた常駐UIを減らし、「盤面のメニュー」から呼び出す形に集約する。空いた画面右側をパネル置き場にする。

- **コマンド一覧**＝何も選んでいないときに**ユニットがいないマス**を左クリックで、そのマスの隣に出る（行動メニューと同じ `ActionMenu` を使い回す）。
  並びは **状況 ／ 設定 ／ 終了**。「終了」を最下段にしたのは誤クリックでターンが終わる事故を防ぐため
- **「終了」**＝自軍フェイズの終了。全員行動済みでの自動ターン終了は別にある（再行動できる味方が残っているときだけ自動で終わらない）
- **「状況」**＝ターン数／ターン制限・フェイズ・クリア条件・両軍の数（味方は未行動数も）・敵の攻撃範囲の表示状態。見るだけ
- **クリア条件はステージのデータではなくコードの判定から自動生成する**（`TurnManager.BuildClearConditionLines` を `CheckGameEnd` の真下に置く）。
  「味方輸送隊の死亡」は輸送隊がいるステージだけ、ターン制限の行は turnLimit>0 だけ出す。
  **勝敗判定を変えたらこの関数も直すこと**
- **「設定」**＝枠と開閉だけで、中身は「準備中」の案内（項目は将来決める）
- **画面レイアウト**: 盤面は画面の**左寄り**（既定で横58%・下10%を空ける）に収める（`boardAreaWidth` / `boardBottomArea`）。
  右側はコマンド一覧・状況/設定・ユニット情報（とその下の敵AIデバッグ表示）の置き場。左上の常駐表示（ターン数・フェイズ）は無い。
  高さ側で大きさが決まっているステージでは、盤面は縮まず位置だけ動く
- カメラは `GridManager.FitCamera` が自動で合わせる。`cam.rect` は使わない（領域外が塗られずゴミが残るため）。`orthographicSize` と位置だけで寄せる
- 既知の副作用: **敵フェイズ中は画面に状態表示が出ない**（操作できないのでコマンド一覧も開けない）

## 盤上の表示と画面サイズの合意仕様

- **ユニットの絵の上には何も描かない**（作者指示）。救出の状態はユニット情報パネルの状態枠で確認できる
- **HP ゲージ**: ユニットのいるマスの**最下部**に、残りHPの割合を横棒で出す。**味方=青／敵=赤**。
  長さは**マス幅の89%からリング2つぶんの直径を引いた長さ**で、**マスの中央に寄せる**（下隅のリングと重ならないため。89% は作者の手調整）。
  太さはマス高の10%（最低3px）・背景は暗いグレー（`Unit.OnGUI`。数値は `Unit.cs` の定数ブロック）
- **メモリ・覚醒のリング**: マスの**左下隅にメモリ、右下隅に覚醒**（作者指示）。外円の直径はマスの一辺の **1/5**。リングの下端は HP ゲージの下端と同じ高さ。
  リングの**真上から反時計回り**に貯まったぶんだけ塗る。色はユニット情報のゲージと同じ（`GaugeBars.MemoryColor` / `MomentumColor` を共用）。
  貯まりきって保持している本数はリングの**真上にリングと同じ大きさの数字**で出す。
  リングと数字は `OnGUI` で描くので、ユニットの絵や HP ゲージより常に手前に見える。
  Claude が決めた既定（作者に伝達済み・`GaugeRings` の定数で変えられる）: リングの太さ＝半径の半分／未蓄積部分は `GaugeBars.BackColor`／ストックは1本以上のときだけ・白い数字に黒い影／敵味方の全ユニットに出す
- **画面サイズ**: ビルドは **1280×720 のウィンドウ表示に固定**（Player Settings: Fullscreen Mode=Windowed・
  Default Screen 1280×720・Resizable Window オフ・Allow Fullscreen Switch オフ）。
  盤面と右のユニット情報パネルは Stage_01 で約73px 離れて重ならない（16:9 で縦631px 未満になると重なる）。
  エディタでは Game ビューの解像度を 1280x720 にして確認する

## 敵の攻撃範囲の表示の合意仕様

**ねらい**: 「どこに立つと敵の攻撃が届くか」を、敵を1体ずつクリックして調べなくても分かるようにする。
見るだけの機能で、中身は `UI/DangerZoneView`。

**Rキー（敵全員の範囲）**

- **Rキーで敵全員の攻撃範囲を薄い赤紫で重ねる**（表示／非表示の切り替え。戦闘開始時は非表示）。
  自軍フェイズのどの操作の途中でも・敵フェイズ中でも・決着後でも効く
- 赤紫になるのは**次の敵フェイズに、どれかの敵の攻撃が届くマス**（`ThreatMap.GetThreatCells`）。
  決まりは敵AIが攻撃先を探すときと同じ＝立ち位置の候補は「移動できるマス＋いまのマス」・
  後衛武器は移動すると最小射程ちょうど・メモリで払えない武器では届かない・壁マスは塗らない。
  **待ち伏せ型の敵も含める**。行動済みかどうかは見ない。敵が順番に動いて空いたマスに止まる分までは読まない（表示用の近似）
- **青い移動範囲にも重なって青紫になる**（作者合意）＝移動先の安全・危険が選ぶ前に分かる。
  混ぜるのはハイライトの無いマスと青だけのマス。黄・赤・橙・緑はいま選んでいる操作の色なので混ぜない。
  色と濃さは `dangerZoneColor` / `dangerZoneBlend`（既定 (0.85,0.3,0.75)・0.35）
- いまの状態はコマンド一覧の「状況」に1行で出す（「敵の攻撃範囲: 表示中／非表示（Rキーで切り替え）」。作者合意）。キーの案内もこの1行が兼ねる
- **赤紫の境目には、塗りより少し濃い紫の線を引く**（作者要望。塗りと一緒に R で出し入れする）。
  範囲に囲まれた穴は、**攻撃が届かない安全なマスだけ線で囲み、壁は囲まない**（作者合意。`GridManager.FillEnclosedWalls`）。盤面の端では端に沿って閉じる。
  線は黄・赤・橙・緑のマスの上にも引く。色と太さは `dangerZoneOutlineColor` / `dangerZoneOutlineThickness`（既定 (0.65,0.2,0.6)・マスの一辺の8%）

**敵の印**

- **何も選んでいないときに敵をクリックすると印が付き**、その敵の範囲（移動できるマス＋本人のマス＋攻撃が届くマス。`ThreatMap.GetUnitRangeCells`）が
  **薄い赤で塗られ、外枠が濃い赤で残る**。何体でも付けられ、**印の付いた敵をもう一度クリックすると外れる**
- **黄・青・橙の下見は、何も選んでいないときに、印の付いた敵へマウスを乗せている間だけ出る**（作者合意。`BattleController.UpdateHoverPreview`）。
  下見はハイライトなので、薄い赤や赤紫より上に見える。印の無い敵に乗せても何も出ない。味方を選んでいる間などは出さない。
  何も選んでいないときの右クリック/ESC は何もしない
- 印が複数あるときは、**範囲を合わせて塗り、外周を1本の枠で囲む**（作者合意）
- **薄い赤を塗るのは範囲のマスそのもの**。混ぜるのはハイライトの無いマスだけで、赤紫より優先する。
  **青い移動範囲には混ぜない**（作者合意。青＋薄い赤と青＋赤紫が似た色になって見分けにくいため）。
  色と濃さは `markedFillColor` / `markedFillBlend`（既定 (1,0.45,0.45)・0.35）
- 外枠なので、範囲に囲まれた内側の穴（城の壁など）は囲まない。盤面の端では端に沿って閉じる。
  枠の内側に実際には届かないマスが入ることがあるが、そのマスは薄い赤で塗られないので見分けられる
- 印はターンをまたいでも残り、敵が動けば付いていく。倒れた敵の印は自動で外れる。ESC・右クリックでは外れない
- 線の色と太さは `markedOutlineColor` / `markedOutlineThickness`（既定 (0.7,0,0)・マスの一辺の8%）
- **印の付いた敵の絵は赤く染まる**（作者要望）。染め方は元の色への掛け算で、色は `markedUnitTint`（既定 (1,0.35,0.35)。白にすると染めない）。
  行動済みの暗さとは重ねがけ。絵の無い兵種は、もともと赤いので濃い赤になるだけ

**描画の決まり**

- 描く順番（奥から）: マス（0）→ 紫の線（1）→ 印の赤い外枠の線（2）→ ユニットの絵（3）。紫と赤が同じ境目に重なったら赤が上に見える
- 描き直しは、何か表示しているあいだ毎フレーム「盤面の様子」（全ユニットの位置・生死・盤上にいるか、敵の装備とメモリ）を数字の並びにして、
  最後に描いたときと比べて違うときだけ計算し直す。これで仮の移動・取り消し・敵フェイズ中の移動・救出にも自動で付いていく
- 色と太さの欄はシーンに保存されていない（スクリプトの既定値で動いている）。
  Inspector で変えて Ctrl+S すると `BattleScene` に書き込まれるので、シーンの差分を確かめてからコミットする

**確認の手がかり**

- Stage_01 の1ターン目は 168 マス中 140 マスが赤紫（移動6の敵4体を除くと 99 マス）。範囲の中の壁 (4,8)(7,8) は囲まない
- 範囲に囲まれた安全なマスは、Stage_01 の1ターン目に 味方兵 (4,1)→(4,4)・味方兵 (5,1)→(4,2)・味方騎兵 (3,1)→(3,3)・
  味方斧兵 (6,1)→(5,3) と動かすと、まん中の (4,3) が紫の四角で囲まれる
