# 盤面と画面の表示の仕様

- ③ 範囲表示: 自軍ユニットを選ぶと移動範囲（水色）の外周に「攻撃だけ届くマス」を赤系で
  重ね表示（BattleController.ComputeAttackCells。壁マスは除外・救出/引き受け/降ろす/引き渡し/人交換の後は非表示）。
  Idle 中に敵をクリックするとその敵の移動+攻撃範囲プレビュー（ShowEnemyPreview。
  空きマスクリック/ESC/右クリック/自軍選択/敵フェイズ開始で解除）。
  ※2026-10-25 から敵のクリックは印の付け外しを兼ねる＝下見が出るのは印を付けたときで、
  印の付いた敵をもう一度クリックすると下見も印も消える（「敵の攻撃範囲の表示の合意仕様」の節）。
  ※2026-10-28 から、下見は何も選んでいないときに印の付いた敵へマウスを乗せている間だけ出る
  （クリックでは出さない・残さない。BattleController.UpdateHoverPreview）。
  ※2026-10-28 から、移動力の範囲にいる仲間のマス（通り抜けるだけで止まれない）は赤ではなく水色で見せる
  （それまでは赤か、周りも仲間で武器が届かない所は色なし。下見の中のほかの敵のマスも同じ）。
  色の注記: スクリプト既定の attackRangeColor は赤 (1, 0.5, 0.5) だが、シーンの直列化値は
  オレンジ (1, 0.7, 0.5) のままで作者テスト済み・承認済み
  （変える場合は GridManager の Inspector で色を変えて Ctrl+S 保存→シーンをコミット）
### コマンド一覧と画面レイアウトの合意仕様（2026-08-15 作者要望）

**ねらい**: 画面の隅に貼り足してきた常駐UIを減らし、「盤面のメニュー」から呼び出す形に集約する。
空いた画面右側を今後のパネル置き場にする（次に予定しているユニット情報UIの刷新もここに置く）。

- **コマンド一覧**＝Idle 中に**ユニットがいないマス**を左クリックで、そのマスの隣に出る（行動メニューと同じ
  ActionMenu を使い回すので、見た目・回り込みの作法も同じ）。並びは **状況 ／ 設定 ／ 終了**。
  「終了」を最下段にしたのは誤クリックでターンが終わる事故を防ぐため
- **「終了」** ＝ 自軍フェイズの終了（旧「ターン終了」ボタン）。全員行動済みでの自動ターン終了は従来どおり
  （再行動できる味方が残っているときだけ自動で終わらない＝フェーズ30 の合意も従来どおり）
- **「状況」** ＝ ターン数／ターン制限・フェイズ・クリア条件・両軍の数（味方は未行動数も）・
  敵の攻撃範囲の表示状態（2026-10-25。Rキーの案内も兼ねる）。見るだけ
- **クリア条件はステージのデータではなくコードの判定から自動生成**（TurnManager.BuildClearConditionLines を
  CheckGameEnd の真下に置く）。「味方輸送隊の死亡」は輸送隊がいるステージだけ、ターン制限の行は turnLimit>0 だけ出す。
  **勝敗判定を変えたらこの関数も直すこと**（拠点到達などを足すときの唯一の注意点）
- **「設定」** ＝ 枠と開閉だけ作り、中身は「準備中」の案内（項目は将来決める）
- **画面レイアウト**: 盤面は画面の**左寄り**（既定で横 58%・下 10% を空ける）に収める。
  右側はコマンド一覧・状況/設定・戦闘予測・ユニット情報（とその下の敵AIデバッグ表示）の置き場。
  **左上の常駐表示（ターン数・フェイズ）は撤去**
  ※**地形情報は 2026-08-17 に「盤面の真下の帯」へ戻した**（作者指示。
  帯 → カーソル追従 → 盤上の4隅 と動かしたが「位置が入れ替わりすぎて注意力を奪う」ため）。
  **横幅は盤面と同じ・高さは1行で固定**。下に空けた 10% がその置き場なので、
  `boardBottomArea` を下げすぎると帯が画面からはみ出す（帯の高さは36px）
  ※**盤上のメニューは盤面の外に出さない**（`UI/MenuPlacement`）＝帯や右側のパネルの領域に
  メニューがはみ出さない。これで帯とメニューが重ならない
  ※横の割合は 2026-08-16 の修正案で 65%→58%（盤面をさらに左へ寄せる作者の指示）。
  高さ側で大きさが決まっているステージでは盤面は縮まず位置だけ動く
- 撤去にともなう既知の副作用: **敵フェイズ中は画面に状態表示が出ない**（操作不可なのでコマンド一覧も開けない）。
  遊んでみて分かりにくければ、敵フェイズ中だけの小さな表示を足す

### 盤上の表示と画面サイズの合意仕様（2026-10-10 作者指示）

- **ユニットの絵の上には何も描かない**。以前の HP の数字と「救」「飛x2」の印は廃止
  （救出の状態はユニット情報パネルの状態枠＝「救出中: 相手の名前」で確認できるため。飛翔は 2026-10-24 に撤廃）
- **HP ゲージ**: ユニットのいるマスの**最下部**に、残りHPの割合を横棒で出す。**味方=青／敵=赤**。
  長さは**マス幅の89%からリング2つぶんの直径を引いた長さ**で、**マスの中央に寄せる**（下隅のリングと重ならないため。
  2026-10-11 作者指示。89% は作者の手調整で、それまではリングを引かずにマス幅の85%）。1280×720 の Stage_01 では約23px。
  太さはマス高の10%（最低3px）・背景は暗いグレー（Unit.OnGUI。数値は Unit.cs の定数ブロック）
- **メモリ・覚醒のリング**: マスの**左下隅にメモリ、右下隅に覚醒**（2026-10-11 作者指示で上隅から変更）。
  外円の直径はマスの一辺の **1/5**。リングの下端は HP ゲージの下端と同じ高さ。
  リングの**真上から反時計回り**に貯まったぶんだけ塗る。色はユニット情報のゲージと同じ
  （GaugeBars.MemoryColor / MomentumColor を共用＝片方を変えれば両方変わる）。
  貯まりきって保持している本数（ストック）はリングの**真上にリングと同じ大きさの数字**で出す
  （2026-10-11 に真下から変更。下隅に移したので、真下だとマスの外にはみ出るため）。
  リングと数字は OnGUI で描くので、ユニットの絵と重なっても**常に手前**に見える（HP ゲージより後に描くのでゲージよりも手前）。
  Claude が決めた既定（作者に伝達済み・GaugeRings の定数で変えられる）: リングの太さ＝半径の半分／
  未蓄積部分は GaugeBars.BackColor／ストックは1本以上のときだけ・白い数字に黒い影／敵味方の全ユニットに出す。
  1280×720 の Stage_01 では1マス約46px なのでリングの直径は約9px
- **画面サイズ**: ビルドは **1280×720 のウィンドウ表示に固定**（Player Settings: Fullscreen Mode=Windowed・
  Default Screen 1280×720・Resizable Window オフ・Allow Fullscreen Switch オフ＝Alt+Enter でも全画面にならない）。
  盤面と右のユニット情報パネル（幅500px固定）は Stage_01 で約73px 離れて重ならない
  （計算上、16:9 で縦631px 未満になると重なる）。エディタでは Game ビューの解像度を 1280x720 にして確認する
- マップの絵は作者の調整で**キャンバスの 0.9 倍**に縮小（Unit.Initialize の localScale に ×0.9）

### 敵の攻撃範囲の表示の合意仕様（2026-10-25 作者要望）

**ねらい**: 「どこに立つと敵の攻撃が届くか」を、敵を1体ずつクリックして調べなくても分かるようにする。
見るだけの機能で、ゲームの状態は一切変えない（中身は `UI/DangerZoneView`。BattleController が自動生成）。

- **Rキーで敵全員の攻撃範囲を薄い赤紫で重ねる**（表示／非表示の切り替え。戦闘開始時は非表示）。
  Rキーはいつでも効く（自軍フェイズのどの操作の途中でも・敵フェイズ中でも・決着後でも）
- 赤紫になるのは**次の敵フェイズに、どれかの敵の攻撃が届くマス**（ThreatMap.GetThreatCells）。
  決まりは敵AIが攻撃先を探すときと同じ＝立ち位置の候補は「移動できるマス＋いまのマス」・
  後衛武器は移動すると最小射程ちょうど・メモリで払えない武器では届かない・壁マスは塗らない。
  **待ち伏せ型の敵も含める**（挑発される前でも、届く相手がいれば動いて攻撃してくる＝Phase 17）。
  行動済みかどうかは見ない（敵フェイズの途中では「いまの盤面から全員がもう一度動いたら」の範囲になる）。
  敵が順番に動いて空いたマスに止まる分までは読まない（表示用の近似）
- **青い移動範囲にも重なって青紫になる**（作者合意）＝移動先の安全・危険が選ぶ前に分かる。
  混ぜるのはハイライトの無いマスと水色だけのマス。黄（選択中）・赤（攻撃対象）・橙（攻撃が届く）・緑（杖）は
  いま選んでいる操作の色なので混ぜない。色と濃さは GridManager の Inspector の
  dangerZoneColor / dangerZoneBlend（既定 (0.85,0.3,0.75)・0.35）
- いまの状態はコマンド一覧の「状況」に1行で出す（「敵の攻撃範囲: 表示中／非表示（Rキーで切り替え）」。作者合意）。
  キーの案内もこの1行が兼ねる
- **赤紫の境目には、塗りより少し濃い紫の線を引く**（2026-10-28 作者要望。塗りと一緒に R で出し入れする）。
  範囲に囲まれた穴は、**攻撃が届かない安全なマスだけ線で囲み、壁は囲まない**（作者合意。壁は誰も立てないので、
  囲んでも線が増えるだけ。GridManager.FillEnclosedWalls）。盤面の端では端に沿って閉じる。
  線は黄・赤・橙・緑のマスの上にも引く（塗りを混ぜないマスでも境目が見える）。
  色と太さは Inspector の dangerZoneOutlineColor / dangerZoneOutlineThickness
  （既定 (0.65,0.2,0.6)＝塗りと同じ色合いを濃くした色・マスの一辺の8%＝印の赤い外枠と同じ）。
  作者の「FE if を参考に」という要望に対し、FE if の画面そのものは確かめられなかったので、作者の説明どおり
  「塗りの境目を同じ系統の濃い色でなぞる」形にした
- **何も選んでいないときに敵をクリックすると印が付き**、その敵の範囲（移動できるマス＋本人のマス＋攻撃が届くマス。
  ThreatMap.GetUnitRangeCells）が**薄い赤で塗られ、外枠が濃い赤で残る**（薄い赤は 2026-10-28 作者要望）。
  何体でも付けられ、**印の付いた敵をもう一度クリックすると外れる**
  - **黄・青・橙の下見は、何も選んでいないときに、印の付いた敵へマウスを乗せている間だけ出る**（2026-10-28 作者要望・合意）。
    下見はハイライトなので、薄い赤や赤紫より上に見える。印を付けたクリックではマウスが敵の上にあるので、そのまま下見が出る。
    印の無い敵に乗せても何も出ない（作者の指定）。味方を選んで移動先を選んでいる間などは出さない（自分の青い範囲が隠れるため）。
    経緯: 2026-10-25 は「1回目のクリックで下見も出し、別のマスのクリック・右クリック/ESC・味方の選択・敵フェイズ開始まで残す」
    だった（作者合意）。薄い赤を入れると、残った下見がクリックした敵の薄い赤を隠すので、マウスを乗せている間だけに変えた。
    何も選んでいないときの右クリック/ESC は、今は何もしない
  - 印が複数あるときは、**範囲を合わせて塗り、外周を1本の枠で囲む**（作者合意）
  - **薄い赤を塗るのは範囲のマスそのもの**（2026-10-28）。混ぜるのはハイライトの無いマスだけで、赤紫（Rキー）より優先する。
    **青い移動範囲には混ぜない**（作者合意。青＋薄い赤と青＋赤紫が似た色になって見分けにくいため。境目は赤い線で見える）。
    黄・赤・橙・緑にも混ぜない（赤紫と同じ）。色と濃さは Inspector の markedFillColor / markedFillBlend
    （既定 (1,0.45,0.45)＝攻撃対象の候補の赤と同じ色・0.35＝赤紫と同じ濃さ。見本で3案を比べて大差なし）
  - 外枠なので、範囲に囲まれた内側の穴（城の壁など）は囲まない。盤面の端では端に沿って閉じる。
    そのため枠の内側にも、実際には届かないマスが入る（Stage_01 の (5,9) の弓兵の死角 (1,9)・(2,8) など）。
    2026-10-28 からは、そうしたマスは薄い赤で塗られないので見分けられる
  - 印はターンをまたいでも残り、敵が動けば付いていく。倒れた敵の印は自動で外れる。ESC・右クリックでは外れない
  - 線の色と太さは Inspector の markedOutlineColor / markedOutlineThickness
    （既定 (0.7,0,0)・マスの一辺の8%＝Stage_01 で約4px）
- **印の付いた敵の絵は赤く染まる**（作者要望）＝範囲を調べている途中の敵だと分かる。印を外すと元の色に戻る。
  染め方は元の色への掛け算で、色は Inspector の markedUnitTint（既定 (1,0.35,0.35)。白にすると染めない。
  敵の絵で候補4つを見比べて、元の絵との違いが一番はっきりするものを選んだ）。
  行動済みの暗さとは重ねがけ＝敵フェイズ中に印の付いた敵が行動すると暗い赤になる。
  絵の無い兵種（赤い四角で出る）は、もともと赤いので濃い赤になるだけで違いは小さい
- 描く順番（奥から）: マス（0）→ 紫の線（1）→ 印の赤い外枠の線（2）→ ユニットの絵（3）。
  紫と赤が同じ境目に重なったら赤が上に見える（自分で選んだ印のほうが細かい情報のため）。
  外枠を絵の下に通すため、ユニットの描画順を 1 → 2（2026-10-25）→ 3（2026-10-28）に上げた
- 描き直しは、何か表示しているあいだ毎フレーム「盤面の様子」（全ユニットの位置・生死・盤上にいるか、
  敵の装備とメモリ）を数字の並びにして最後に描いたときと比べ、違うときだけ計算し直す。
  これで仮の移動・その取り消し・敵フェイズ中の敵の移動・救出にも自動で付いていく
  （味方のマスは敵が通れないので、味方が動くだけで敵の範囲が変わることがある）
- 参考の数字: Stage_01 の1ターン目は 168 マス中 140 マス（83%）が赤紫（WSL での事前計算と Play のログが一致）。
  移動6の敵4体を除くと 99 マス。紫の線は 54 本（盤の端に沿う 33 本＋味方の初期配置側との境目 21 本。
  表示に切り替えた直後のログに本数も出る）。範囲の中の壁 (4,8)(7,8) は囲まない。
  敵槍騎兵2体に印を付けると、赤い線 42 本のうち 16 本が紫と重なる（どれも WSL での事前計算）。
  同じ2体の印で薄い赤は 59 マス（R も押すと赤紫は残り 81 マス）、(12,7) の印を外すと 56 マス。
  敵弓兵 (5,9) に印を付けると、枠の内側 52 マスのうち塗るのは 48 マス（死角 (1,9)(2,8) と壁 (4,8)(7,8) は塗らない）
- 範囲に囲まれた安全なマスは、今あるステージの1ターン目には無く、Stage_01 で味方1体を動かしても出ない（総当たりで確認）。
  確かめるなら Stage_01 の1ターン目に 味方兵 (4,1)→(4,4)・味方兵 (5,1)→(4,2)・味方騎兵 (3,1)→(3,3)・
  味方斧兵 (6,1)→(5,3) と動かすと、まん中の (4,3) が紫の四角で囲まれる（139 マス・線 60 本の見込み）
- ※ここに出てくる色と太さの欄は、まだシーンに保存されていない（スクリプトの既定値で動いている）。
  Inspector で変えて Ctrl+S すると BattleScene に書き込まれるので、シーンの差分を確かめてからコミットする
