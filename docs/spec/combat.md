# 戦闘の仕様

命中は必中（命中・回避の乱数なし）で、反撃も基本はない。ダメージはプレイヤーが完全に計算できる。

- 可否と補正の判定は `Combat/CombatRules` に一元化する。プレイヤー操作・敵AI・戦闘予測は必ず同じ関数を呼ぶ
- ダメージの計算は `DamageCalculator`、攻撃1回の解決は `CombatSystem.ResolveAttack`
- 合計ダメージの予測は `CombatSystem.PredictTotalDamage`（挟撃・ガード込み。敵AIの評価も同じものを見る）
- 反撃の拡張点は `CombatSystem.CanCounter` だけ（いまは常に false）
- 武器の分類と一覧は [weapons.md](weapons.md)、必殺技は [gauges.md](gauges.md)

## ダメージの式

ダメージ = max(0, 攻撃 + 武器威力×特効倍率 + 三すくみ補正 − (防御 + 地形防御))

- 能力値は7種（HP・力・魔力・技・速さ・守備・魔防）
- 物理＝力 vs 守備、魔法＝魔力 vs 魔防。地形防御はどちらにも加わる。飛行兵は地形防御を受けない
- 魔法ダメージの判定は `WeaponData.DealsMagicDamage`（魔導書・光魔法の武器種と、魔法武器の印 `magicDamage` を持つ武器）
- 特効倍率は武器威力にだけ掛かる。必殺技の2倍はダメージ全体に掛かる別の段で、端数は切り捨て

## 三すくみ

- 前衛武器の攻撃は相性表で決まる: 剣＞斧＞槍＞剣
- 有利側が攻撃 = +max(2, 攻撃側の技 − 防御側の速さ)
- 有利側が防御 = −max(2, 防御側の速さ − 攻撃側の技)
- 前衛武器の攻撃を受けた後衛武器・非武装の相手は「非武装扱い」で、攻撃側が有利になる
- 後衛武器の攻撃は相性表を使わず、静止撃ちのときだけ有利になる（下の節）
- 三すくみ逆転: アーマーキラー・斬馬刀・風薙ぎの剣は、槍を持つ重装・騎馬・白翼の相手との有利不利が入れ替わる（[weapons.md](weapons.md)）

## 攻撃の射程

- 前衛武器は武器の射程どおり
- 後衛武器は、移動後は最小射程（2マス）ちょうど、静止時（自マスをクリック）は 2〜武器の上限（弓3・長弓4・魔導書2）
- 非武装・杖・メモリで払えない武器には射程が無い＝攻撃できない（`CombatRules.TryGetAttackRange`）。
  非武装のユニットには攻撃コマンドを出さない

## 静止撃ちの合意仕様

**ルール**（作者合意）

- 後衛の攻撃武器（弓・魔導書・光魔法）で**マスから動かずに**攻撃すると、三すくみ有利が付く
- 補正量は前衛の有利と同じ式 = +max(2, 攻撃側の技 − 防御側の速さ)。技と速さが後衛武器の戦闘でも意味を持つ
- 相手の武器種は問わない（前衛・後衛・杖・非武装のどれでも有利）。後衛の攻撃が不利になることは無い
- 移動してから撃つと補正なし（±0）。「移動したか」は後衛武器の射程が縮む判定と同じものを使う
  （プレイヤー＝`ActionContext.hasMoved`、敵AI＝立ち位置 ≠ 元の位置）。
  交換しただけ・持ち物を操作しただけなら、動いていない扱い
- 杖は攻撃できないので対象外。挟み役は必ず前衛武器なので関係しない

**実装の決まり**

- 判定は `CombatRules.GetTriangleModifier(attacker, defender, attackerHasMoved)` の1か所。
  有利の式は `AdvantageBonus` にまとめて前衛の有利と共有する（片方だけ変わらないように）
- `attackerHasMoved` の既定は true（補正なし側）。渡し忘れても補正が勝手に付かない向きに寄せてある
- `PredictTotalDamage` の `attackerHasMoved` は必須引数。実行時は移動を済ませてから呼ぶこともあり、
  「fromCell が現在地」でも静止を意味しないため、呼び出し側が明示する
- 敵AIは立ち位置ごとの hasMoved を `ScoreAttack` へ渡すので、弓・魔法の敵は「その場で撃つ」手を自然に高く評価する。
  実行するときは移動する前に hasMoved を控える
- AIの控えめな被害見積り（集中攻撃の候補評価・`ThreatMap` の挟撃の脅威）は静止撃ち有利を数えない
  （その敵が動くかどうかがその時点で決まっていないため）

## 挟撃とガード

- **挟撃**: 近接攻撃のとき、敵を挟んだ反対側の隣マス（上下左右の一直線・斜めは対象外）に前衛武器の味方がいれば、その味方も追加で攻撃する。
  参加した味方は行動を消費しない。遠距離攻撃や、後衛武器・非武装の味方では成立しない
- **ガード**: 防御側の隣接4マスに、同陣営の「前衛武器の徒歩ユニット」がいると挟撃は成立しない。
  ガード役自身は守られない。行動済みでも有効。敵味方で対称
- 挟撃の支援役は自分の武器のメモリ消費を払う。払えなければ挟撃は起きない。ガード役にメモリは要らない（[weapons.md](weapons.md)）
- 飛行兵も隣の前衛徒歩ユニットに守られる
- 挟撃の追撃に必殺技の倍率は乗らない。有効・特効は乗る（挟み役の武器で別に計算する）
- 敵AIの使い方は [enemy-ai.md](enemy-ai.md)

## 有効と特効の合意仕様

作者の仕様書 `Desktop/有効と特効の仕様書.md`（作者所有）が原本で、相手の一覧や算数の詳細はあちらにある。

**ルール**

- **有効＝武器威力2倍／特効＝武器威力3倍**。倍になるのは武器威力だけで、ダメージ全体ではない
- 相手の判定は移動タイプではなく**兵種の特攻タグ**（`ClassTag`: 騎馬・白翼・竜・重装・竜騎兵）。
  飛行兵の中に白翼と竜騎兵の両方がいるので、移動タイプでは書き分けられないため
- 武器種そのものが持つ相性（「全ての槍は」というルールなので、アセットではなくコードの表が持つ）
  - 前衛＝有効: 槍→騎馬・白翼／斧→重装・竜騎兵
  - 後衛＝特効: 弓→白翼／魔導書→竜（竜騎兵も含む）。剣・杖・光魔法は無し
- 個別の特効武器は `WeaponData.effectiveTags` で武器ごとに持ち、すべて特効（3倍）。一覧は [weapons.md](weapons.md)
- **重なったときは一番大きい倍率1つだけ**（作者合意）。鎧騎馬兵（騎馬＋重装）をハンマー（重装特効）で殴っても3倍で、
  斧の重装有効2倍とは足し算も掛け算もしない
- **竜騎兵属性は竜属性に含まれる**（作者指示）。竜騎兵・大竜騎兵・魔竜騎兵が竜騎兵タグ。
  斧の有効は竜騎兵にだけ効き、魔導書と竜特効の武器（ドラゴンキラー・ドラゴンアクス・ドラゴンボウ）は竜（竜騎兵も含む）に効く。
  竜タグを持つ兵種はいま0で、将来の「竜」ユニット用に空けてある
- 白翼属性＝白翼騎兵・聖白翼騎兵・金鵄兵
- 杖の回復には関係しない。非武装では特効も無い。メモリで払えない武器は攻撃に使えないので特効も乗らない

**表示**

- 武器の説明（持ち物の詳細・ユニット情報の持ち物の詳細。`EffectiveRules.BuildWeaponEffectLines`）は、
  竜を狙う武器なら竜に含まれる属性まで並べる（`Cover`）＝初級魔導「特効: 竜・竜騎」／鉄の斧「有効: 重装・竜騎」／
  ドラゴンアクス「特効: 竜・竜騎」「有効: 重装」／鉄の弓「特効: 白翼」／鉄の槍「有効: 騎馬・白翼」。
  「特効: 竜」だけだと、竜騎兵属性が竜に含まれる決まりを知らない人には竜騎兵に効くと読み取れないため（作者指摘）
- **「竜騎」は竜騎兵属性の短い呼び名で、武器の説明（三すくみ逆転の行も含む）だけで使う**（作者指示）。
  「竜騎」は他の作品の題名と被るので、短い表記が要る場所に限る。`ClassTagExtensions.DisplayName(shortForm: true)`
- **戦闘予測の注記は正式名で、撃つ相手自身の属性**を出す（`EffectiveRules.GetMatchedTags`）。
  初級魔導→竜騎兵「※特効: 竜騎兵（武器威力3倍）」／鉄の斧→竜騎兵「※有効: 竜騎兵（武器威力2倍）」。
  出るのは兵種名ではなく属性名で、大竜騎兵・魔竜騎兵を撃っても「竜騎兵」と出る
- Console のログの式は「威力5×3」の形
- Inspector の表示名は正式名「白翼」「竜騎兵」

**実装の要点**

- 判定の窓口は `EffectiveRules.GetMultiplier(weapon, defender)` 1つで、差し込みは `DamageCalculator` の1か所だけ。
  戦闘本体・挟撃・敵AIの見積り・戦闘予測が自動で同じ倍率を見る（敵AIの点数定数の追加は不要）
- 包含関係（竜騎兵→竜）は `ClassTagExtensions` に集約する。判定用の `Expand`（ユニット側のタグを広げる）と
  表示用の `Cover`（武器が狙うタグを広げる）の2方向。兵種アセットには竜騎兵だけを付ける約束
