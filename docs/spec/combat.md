# 戦闘の仕様

### 静止撃ちの合意仕様（2026-07-30 作者合意）

**ルール**

- 後衛武器（弓・魔導書・光魔法）で**マスから動かずに**敵を攻撃すると、その攻撃に**三すくみ有利**が付く
- 補正量は前衛の有利と**まったく同じ式** = +max(2, 攻撃側の技 − 防御側の速さ)（最低2）。
  技・速さが後衛武器の戦闘でも意味を持つようになる
- **相手の武器種は問わない**（前衛・後衛・杖・非武装のどれでも有利）。後衛の攻撃が不利になるケースは無い
- 移動してから撃つと補正なし（±0）。「移動したか」は**後衛武器の射程が縮むのと同じ判定を共有**する
  （プレイヤー＝ActionContext.hasMoved、敵AI＝立ち位置 ≠ 元の位置）
- したがって交換しただけ・持ち物を操作しただけなら「動いていない」扱い（既存の hasMoved の意味そのまま）
- 杖は攻撃できないので対象外。挟み役（必ず前衛武器）にも関係しない

**実装**

- 判定は `CombatRules.GetTriangleModifier(attacker, defender, attackerHasMoved)` の1か所。
  有利の式は `AdvantageBonus()` に切り出して前衛の有利と共有（片方だけ変わらないように）
- attackerHasMoved は DamageCalculator → CombatSystem → 呼び出し側へ通す。**既定は true**（＝補正なし側）で、
  渡し忘れても補正が勝手に付かない向きに寄せてある
- `CombatSystem.PredictTotalDamage` は attackerHasMoved を**必須引数**にした（fromCell から自動判定しない。
  実行時は移動を済ませてから呼ぶこともあり「fromCell ＝ 現在地」が静止を意味しないため）
- 敵AI: Evaluate は立ち位置ごとの hasMoved を ScoreAttack → PredictTotalDamage へ渡すので、
  弓・魔法の敵は「その場で撃つ」を自然に高く評価する。Execute は**移動する前に** hasMoved を控えてから攻撃する
- AIの控えめな被害見積り（EnemyAI の集中攻撃の候補評価・ThreatMap の挟撃脅威）は静止撃ち有利を数えない
  （その敵が動くかどうかはその時点で決まっていないため。既定 true のまま）

**UI（BattleForecast）**

- 与ダメ: 実際に移動したかで**確定した数字**を出す。後衛武器のときは理由の1行を添える
  （「※マスから動かずに撃つため、三すくみ有利がつく」／「※移動して撃つため、静止撃ちの三すくみ有利なし」）
- 被ダメ確認: 敵が動くかは事前に確定できないので、相手が後衛武器のときだけ
  「移動時／静止時」の2行＋三すくみの両方の値＋HPの両方の結果を並べる（DrawIncomingBothCases）

### 有効と特効の合意仕様（2026-08-06〜08 作者合意）

作者の仕様書 `Desktop/有効と特効の仕様書.md`（原案＋16節の確定版。作者所有）をもとに実装した。
相手の一覧や算数の詳細はあちらが原本で、ここには決まったことと実装の要点だけを置く。

**ルール**

- **有効＝武器威力2倍／特効＝武器威力3倍**。倍になるのは武器威力だけでダメージ全体ではない
  （2026-08 当時の武器は威力5なので有効で+5点・特効で+10点。2026-10-24 の作り替えで威力は武器ごとに違う＝鉄の剣6・鉄の弓8 など）
- 相手の判定は移動タイプではなく**兵種の特攻タグ**（ClassTag: 騎馬・白翼・竜・重装・竜騎兵。
  2026-10-24 に天馬→白翼、亜竜→竜騎兵へ改名＝数字の値は不変）
- **武器種そのものが持つ相性**（アセットではなくコードの表が持つ。「全ての槍は」というルールのため）
  - 前衛＝有効: 槍→騎馬・白翼／斧→重装・竜騎兵
  - 後衛＝特効: 弓→白翼／魔導書→竜（竜騎兵も含む）。剣・杖・光魔法は無し（光魔法は当面）
- **個別の特効武器**（11本）は `WeaponData.effectiveTags` で武器ごとに持つ。すべて特効（3倍）
- **重なったときは一番大きい倍率1つだけ**（掛け合わせない）。鎧騎馬兵（騎馬＋重装）を
  ハンマー（重装特効）で殴っても3倍で、斧の重装有効2倍とは足し算も掛け算もしない
- **竜騎兵属性（旧・亜竜）は竜属性に含まれる**（2026-08-06 追加指示・2026-10-24 改名）。竜騎兵・大竜騎兵・魔竜騎兵が竜騎兵タグ。
  斧の有効は竜騎兵にだけ効き、魔導書と竜特効の武器（ドラゴンキラー・ドラゴンアクス・ドラゴンボウ。2026-10-24）は竜（＝竜騎兵も含む）に効く。
  白翼属性（旧・天馬）＝白翼騎兵・聖白翼騎兵・金鵄兵
  竜タグを持つ兵種は現時点で0＝将来ユニットとして追加する「竜」そのもの用に空けてある
- **挟撃の追撃にも乗る**（挟み役は自分の武器で別に計算する）。**杖の回復には関係しない**
- 非武装では特効も無い（フェーズ31の「傷んだ武器では消える」は耐久ごと撤廃。2026-10-24 から、メモリで払えない武器は
  攻撃に使えないので特効も乗らない）

**対空状態**（2026-08-06〜08。前衛の特効武器に対空を付け、特効の相手にだけ働かせていた）は、
2026-10-24 に飛翔・対空ごと撤廃した（「撤廃した仕組み: 飛翔・対空・撃墜」の節）。ドラゴンキラーなどは特効だけが残る。

**表示（2026-10-24 作者指摘で変更）**

- **武器の説明**（持ち物の詳細・ユニット情報の持ち物の詳細。`EffectiveRules.BuildWeaponEffectLines`）は、
  竜を狙う武器なら竜に含まれる属性まで並べる（`Cover`）＝初級魔導「特効: 竜・竜騎」／鉄の斧「有効: 重装・竜騎」／
  ドラゴンアクス「特効: 竜・竜騎」「有効: 重装」／鉄の弓「特効: 白翼」／鉄の槍「有効: 騎馬・白翼」。
  以前は「特効: 竜」だけで、竜騎兵属性が竜に含まれる決まりを知らないと竜騎兵に効くと読み取れなかった
- **「竜騎」は竜騎兵属性の短い呼び名で、武器の説明（三すくみ逆転の行も含む）だけで使う**（作者指示。
  「竜騎」は他の作品の題名と被るので、短い表記が要る場所に限る）。`ClassTagExtensions.DisplayName(shortForm: true)`
- **戦闘予測の注記は正式名で、撃つ相手自身の属性**を出す（`EffectiveRules.GetMatchedTags`＝相手のタグ ∩ Cover した狙い）。
  初級魔導→竜騎兵「※特効: 竜騎兵（武器威力3倍）」／鉄の斧→竜騎兵「※有効: 竜騎兵（武器威力2倍）」
  （出るのは兵種名ではなく属性名。大竜騎兵・魔竜騎兵を撃っても「竜騎兵」と出る）
- Inspector の表示名（InspectorName）と CLAUDE.md は正式名「白翼」「竜騎兵」

**数値（Stage_01 の実数。レビュー時に作者へ提示済み。※2026-08 当時の武器の威力5での数字。作り替え後は
「メモリゲージで払う武器の合意仕様」の節の算数）**

- 味方弓兵 → 敵槍飛行兵（HP18/守2）: 9（静止11）→ **19（静止21）＝一撃撃破**
- 敵弓兵 → 味方飛行兵（HP20/守2）: 8（静止10）→ **18（静止20）＝静止撃ちで即死**
- 敵槍騎兵 → 味方騎兵（HP22/守3）: 10 → 15／輸送隊（HP20/守5）: 8 → 13（**2体で26＝即敗北**）
- 味方兵＋斬馬刀 → 敵槍騎兵: 6（剣は槍に不利）→ **16**＝特効は三すくみの不利を覆す

**実装の要点**

- 判定の窓口は `Combat/EffectiveRules.cs` の `GetMultiplier(weapon, defender)` 1つ。
  差し込みは `DamageCalculator` の1か所だけで、戦闘本体・挟撃・敵AIの見積り・戦闘予測が
  自動で同じ倍率を見る（**敵AIの点数定数は追加不要**。杖の回復はここを通らないので影響なし）
- 包含関係（竜騎兵→竜）は `ClassTagExtensions` に集約。判定用の `Expand`（ユニット側のタグを広げる）と
  表示用の `Cover`（武器が狙うタグを広げる）の2方向。**兵種アセットには竜騎兵だけを付ける**約束
  （竜も付けて構わないが、包含を受け持つのはコードの表という取り決め）
- `DamageBreakdown.mightMultiplier` は武器威力にだけ掛かる（必殺技の倍率はダメージ全体に掛かる
  別の段）。struct の既定0を1とみなす書き方は既存の `Multiplier` と同じ
- 表示は式の中が「威力5×3」（行の幅に限りがあるため「＝15」までは書かない）＋理由の1行
  `※特効: 白翼（武器威力3倍）`。ユニット情報と持ち物詳細には `特効: 竜・竜騎` の行（上の「表示」の段）

**やり残し（作者と相談すること）**

- 光魔法の武器種由来の特効は当面なし（武器アセット自体が未作成。作るときに一緒に決める）
- 特効が乗ったときの視覚表現（ダメージ数字の色・効果音）は仮素材のままなので将来
- 弓・魔導書の特効が一撃必殺になる件は、原案どおり3倍で入れてある。手応えを見て判断する
- 将来の「竜」ユニットの兵種設計（竜には弓の白翼特効も斧の竜騎兵有効も効かないので、
  対抗手段は魔導書・竜特効の武器（ドラゴンキラー・ドラゴンアクス・ドラゴンボウ）・素の火力だけになる）
- 検証が終わったら BattleScene の Stage を Stage_01 に戻して Ctrl+S
  （Stage_EffectiveTest への差し替えはコミットしない運用）

### Phase 8 以降の追加合意（2026-07-08）

- 武器分類: 剣・斧・槍＝前衛武器、弓・魔法＝後衛武器（WeaponData にカテゴリ欄を追加、データ駆動）
- 新しい三すくみ補正（Phase 9 で移行）: 有利側が攻撃 = +max(2, 攻撃側の技 − 防御側の速さ)、
  有利側が防御 = −max(2, 防御側の速さ − 攻撃側の技)。旧 ±1 固定は廃止
- 敵AIは新戦闘ルールに追随させる。救出・飛翔コマンドは当面敵は使わない（飛翔は Phase 20 で敵も使うようにし、2026-10-24 に撤廃）
- メニューUIは IMGUI で簡易実装（uGUI 化は素材差し替え時期にまとめて）
- 必中（RNGなし）・反撃なし（CanCounter フック維持）・ScriptableObject データ駆動は継続
- 育成要素（レベル・経験値・成長率）はロードマップ外（将来枠）
