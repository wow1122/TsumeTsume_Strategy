# 持ち物・交換・杖の仕様

画面のコマンド名は「持ち物」、データと内部の用語は「所持品」（`ItemData`・`ItemListMenu` など）。

- 判定は、交換が `Units/ExchangeRules`、杖が `Combat/StaffRules` に一元化されている（`CombatRules` / `RescueRules` と同じ方針）
- 敵AIは持ち物・道具・杖・交換を使わない
- 持ち物の詳細の文言と幅の制約は [ui-panels.md](ui-panels.md)

## 所持品（インベントリ）の合意仕様

**データ**

- 所持品は `UnitData.items`（`List<ItemData>`・上限7＝定数 `InventoryCapacity`）。一番上の武器が初期装備。
  items が空なら旧 weapon 欄1つを持っている扱い（`GetInitialItems` / `GetInitialWeapon`）
- 種類は武器（`WeaponData`）と道具（`ToolData`）の2つ。どちらも抽象基底 `ItemData`（`DisplayName` のみ）の子
- 戦闘中は `Unit.Items`（`ItemSlot`＝item＋残り回数 `UsesLeft`）で持ち、装備中の武器は `Unit.EquippedWeapon`。
  戦闘・AI・UI は `Unit.Weapon` 窓口を読む（`UnitData` を直接読まない）

**操作**

- 装備の持ち替え・外す（非武装になる）・捨てるは**行動を消費しない**（作者合意）。同じ行動で持ち替えて攻撃できる。
  移動を取り消しても装備は戻らない
- 行動メニューの「持ち物」から選ぶ。**操作は2段階**: リストの項目をクリックすると、リストと詳細を残したまま、
  右隣に必ず2ボタンのサブメニューが出る（作者要望）

  | 項目 | サブメニュー |
  |---|---|
  | 装備中の武器 | 外す／捨てる |
  | 装備できる武器 | 装備／捨てる |
  | 装備できない武器 | 装備（灰色）／捨てる |
  | 道具 | 使う（満タンは灰色）／捨てる |

- 装備・外すの後はメニューを開き直す（攻撃対象などが新しい装備で計算し直される）
- 項目にホバーすると、武器（種類・前衛後衛・威力・射程）／道具（効果・使用回数）の性能が**画面右下の定位置**に出る
- メモリで払えない武器も「装備」は押せる（攻撃に使えないだけ。行に「（メモリ不足）」の目印）
- 救出・引き受けなどの後のメニューには「持ち物」が出ない（その行動の制限を保つため）

**捨てる**

- `Unit.DiscardItem`。リストから消え、装備中の武器を捨てたら自動で非武装になる
- 変わるのは戦闘中の `Items` だけ＝その戦闘の間だけ消え、次の戦闘では `Unit.Initialize` で元に戻る
- 行動を消費しない。捨てた後は更新されたリストへ戻る（空なら行動メニュー）

**道具**

- 傷薬（`Tool_Vulnerary`・HP10回復×3回）は**使うと行動終了**（作者合意）
- 効果は使用者自身のHP回復（`Unit.UseTool` → `Unit.Heal` で最大HPを超えない・残り回数-1・0で所持品から消える）。
  `Heal` は杖の回復と共通の土台
- HP満タンでは「使う」が押せない。開始時は全員満タンなので、確認するには敵に攻撃させて負傷させてから

## 杖（ライブ）の合意仕様

- 杖は攻撃できない後衛武器。Stage_01 の担い手は**味方修道士**（兵種 `Class_Monk`）。所持品は [ライブ, 傷薬]、初期装備はライブ
- 「杖」コマンド: 杖を装備し、回復できる相手が射程内にいるとき、攻撃と同じ位置に出る。
  回復対象を緑で選び、クリックで回復して**行動終了**（作者合意）
- 回復量 = **使用者の魔力 + 杖の威力**（作者合意。ライブは威力10・射程1〜1。修道士 魔力6＋10＝16）。最大HPは超えない
- 回復対象＝同陣営・生存・HP満タン未満・射程内。自分は対象外
- ライブはメモリ消費0＝回復回数の制限なし
- 範囲の表示: 選択時に、移動範囲（青）の外側へ「杖が届くマス」を緑で出す（`HighlightKind.HealRange`。攻撃の範囲とは排他）。
  杖の射程は攻撃の後衛武器と違い、移動しても縮まない（攻撃ではないため）。
  移動力の範囲にいる仲間のマスは緑ではなく青（作者合意）。緑は移動の外側だけに残る
- 対象選択は既存の `State.UnitTargetSelect` に purpose Heal を足して再利用する（ハイライト色を引数にして、救出系は赤・杖は緑）
- 敵からは「非武装扱い」で不利に殴られる（杖は後衛武器なので、前衛の攻撃の三すくみがそのまま効く）

## 交換の合意仕様

隣接する同陣営ユニットとの持ち物の受け渡し。行動メニューの「持ち物」の直後・「待機」の直前に、交換できる相手が1体以上いるとき出る。

**相手**

- **隣接4マス（上下左右）の同陣営・盤上のユニット**のみ。斜めは対象外
- **行動済みの味方も相手にできる**（受け取る側は受け身で行動を消費しない）。受け取っても相手の行動済みは変わらない
- **格納中の貨物とは交換できない**。運び手を経由して貨物の持ち物に触ることもできない。運び手自身との交換はできる

**行動と取り消し**

- **交換は行動を消費しない**（作者合意）。渡した後も同じ行動で攻撃・被ダメ確認・杖・道具・持ち物・待機を選べる。
  FE の慣例（渡すと行動終了）とは違うが、「持ち物まわりの操作はすべて消費なしで一貫させる」を作者が選んだ。
  1ターンに何度でも交換できる（強すぎると感じたら「交換後は再移動→待機のみ」に絞る余地は残してある）
- **1個でも動かしたら、その行動は取り消し不能になる**（作者合意。`ActionContext.Commit`）。
  移動の取り消しは交換したマスまでしか戻らず、選択解除もできない。相手の状態を変える操作は巻き戻せない、という救出系と同じ線引き。
  **1個も動かさずに閉じたときは何も起きていない扱い**（作者合意。誤操作の救済）
- 移動後に交換できる（隣接の判定は移動後の位置）。交換後も、使っていない移動力の範囲で再移動できる
- **要注意**: 交換からは `Commit(keepHasMoved: true)` で呼ぶ。交換は確定後もそのまま攻撃できるので、
  移動済みを解除すると「移動した弓兵が交換すると移動していないことになり、後衛武器の射程が2マスちょうど→武器上限まで伸びる」抜け穴になる

**品の受け渡し**

- **双方向・1回の交換で何個でも**動かせる（作者合意）。品は1つずつクリックで反対側へ移る
- 上限は `InventoryCapacity`（7）。**いっぱいの相手へは渡せない**（渡す側の行が灰色の無効行になり、列の見出しに「※いっぱい（受け取れない）」が出る）。
  相手がいっぱいでも「もらう」方向はできるので、交換画面は開ける（持ち物0個のユニットでも開ける）
- **装備中の武器も渡せる。渡すと自動で非武装になる**（「捨てる」と同じ）。確認ダイアログは出さない（列の見出しの「装備: なし」で気づける）
- **兵種が装備できない武器も渡せるが、装備はできない**（「（装備不可）」表示）。受け取っても自動装備はしない
- **道具の残り回数はそのまま引き継ぐ**。`Unit.TransferItemTo` が `ItemSlot` ごと移す。
  受け側で `new ItemSlot` を作ると回数が満タンに戻る（渡すと回復する裏技になる）ので禁止
- 受け取った側は、そのターンまだ行動していなければすぐ使える。行動済みなら次のターン

**画面**

- 相手選択は既存の `UnitTargetSelect` に purpose Exchange を足して再利用する（候補は赤・情報パネルの見出しは「交換する相手」）
- 交換画面は `ItemListMenu` の2列モード（左＝自分／右＝相手。列見出しは 名前／HP・持ち物 n／7・装備武器）。
  相手の情報は列の見出しで見せるので、ユニット情報パネルの文脈表示は畳む。持ち物が無い列は「（持ち物なし）」の無効行1つ
- キャンセルは右クリック/ESC で1段ずつ（交換画面→行動メニュー→移動取り消し）
- 判定を `ExchangeRules` に、UI を「2つの持ち物を並べて品を移すだけ」に保っているので、相手が「預かり枠」や「店の在庫」に変わっても同じ画面を使い回せる
