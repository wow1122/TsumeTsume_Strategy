# 武器の仕様

武器の分類、攻撃のたびにメモリゲージを払う決まり、武器の一覧、攻撃時の武器選択。

- メモリの判定は `Combat/WeaponMemoryRules`、武器選択の判定は `Combat/WeaponChoiceRules` に一元化する
- データは `WeaponData`（`Assets/_Game/Data/W_*.asset`）
- 確認は `Stage_WeaponTest`（[stages-assets.md](stages-assets.md)）
- ダメージの式・三すくみ・有効と特効は [combat.md](combat.md)、メモリの貯まり方は [gauges.md](gauges.md)

## 武器の分類

- 前衛武器（Melee=0）＝剣・斧・槍。後衛武器（Ranged=1）＝弓・魔導書・光魔法・杖。`WeaponData.category` で持つ
- 武器種 `WeaponType` は7種: 剣・槍・斧・弓・魔導書（＝魔法。同じ武器）・杖・光魔法（定義のみ）。
  値は `.asset` に数字で保存されるので、追加は必ず末尾に行う
- 杖は攻撃できない後衛武器で、回復に使う（[items.md](items.md)）
- 武器を装備していない状態は**非武装**と呼ぶ（作者指示）

## メモリゲージで払う武器の合意仕様

作者の仕様書 `Desktop/# メモリゲージ使用による武器仕様改善案.md` に基づく。

**ルール**

- 武器で1回攻撃するたびに、その武器のメモリ消費（`WeaponData.memoryCost`）を払う。鉄の武器・杖は0
- **払い方は本数も崩して合計から**（作者合意）: 合計＝本数×30＋値。1本＋3＝33 から5を払うと 0本＋28
- **装備はメモリに関係なくできる**（兵種が扱える武器なら）。**払えない武器では攻撃できない**
  ＝攻撃の武器一覧で「（メモリ不足）」の灰色行。持ち物の行にも同じ目印が付き、
  ユニット情報の持ち物の行の右端「消費N」が赤字になる
- 攻撃を受けたときは**装備している武器どおりに働く**（作者合意）＝三すくみ・挟撃のガード役にメモリは要らない。
  メモリが要るのは**攻撃と挟撃の支援だけ**。非武装扱いにすると、攻撃の後に持ち替える操作を忘れた人だけが損をするため
- **挟撃の支援役も自分の武器の消費を払う**。払えなければ挟撃は起きない
- 払うのは戦闘の判定がすべて終わってから、攻撃側 → 挟撃の支援役の順。
  途中で払うと、挟撃の成立判定や覚醒の配分がその一撃の中でずれるため
- **味方は自動で持ち替えない**（作者合意）: 払った後にその武器を払えなくなっても装備したまま。
  次の攻撃で武器の一覧から払える武器を選ぶ（選ぶと装備も替わる）。
  いま何を装備しているかを自分の操作の結果にした方が、ルールを理解しやすいため。
  マップ開始時も初期装備のまま始める（初期装備の消費が技を上回ると Inspector で警告）
- **敵だけは自動で持ち替える**（作者合意。敵は武器を選ぶ操作を持たないため）: 払えなくなったら、
  持ち物のうち兵種が装備できて払える武器の中で**消費の低い順・同じなら持ち物の上の方**へ（無ければ非武装）。
  マップ開始時にも同じ判定をする。いまの敵は全員が消費0の武器しか持たないので、どのステージでもまだ起きない
- **必殺技は「1本（30）＋その武器の消費」**: 両方払える武器だけが一覧で選べる
- 消費・支援の条件は敵味方対称。メモリは敵にも貯まる

**武器の特性**

- 鋼の武器・中級魔導: 装備中は**速さが移動力ぶん下がる**（0未満にならない。飛行兵は移動6なので −6）。
  `Unit.Speed` 窓口で効くので、三すくみの補正と覚醒の貯まり方の両方に効く。ユニット情報の速さは「2(-3)」
- 魔法武器（ソニックソード・フレイムランス・ボルトアクス・シャイニングボウ）: **魔力 vs 魔防**で計算する。
  三すくみ・有効・特効は武器種のまま。射程は前衛の3本が1（作者回答）、シャイニングボウは弓の射程（静止2〜3・移動後2）
- 三すくみ逆転（アーマーキラー＝重装・斬馬刀＝騎馬・風薙ぎの剣＝白翼）: 相手がそのタグを持ち、かつ
  剣に勝つ武器（槍）を装備しているとき、**有利と不利が入れ替わる**。攻めるとき・攻められるとき・
  挟撃の追撃のすべてに効く。戦闘予測に「※三すくみ逆転（斬馬刀）」が出る
- 長弓: 最大射程だけ+1（静止2〜4・移動後2）。**弓聖（Class_Sniper）専用**。
  武器ごとの兵種の限定は `WeaponData.exclusiveClasses`。ほかの兵種では「装備不可」
- **剣は敵を倒すと1マス再移動できる**: 剣で攻撃した戦闘で相手が倒れたら（挟撃のとどめ・必殺技も含む）、
  上下左右の1マスへ動ける。地形のコストは問わない（入れない地形・誰かがいるマスは不可）。
  動かずに終えてもよい（自分のマス・右クリック・ESC）。勝利が決まった・動けるマスが無いときは出ない。
  **敵AIは使わない**
- 槍＝騎馬・白翼に有効／斧＝重装・竜騎兵に有効／弓＝白翼に特効／魔導書＝竜（竜騎兵も含む）に特効
  （[combat.md](combat.md) の有効と特効の節）

**いまの数値での算数（Stage_01）**

- メモリは技の値で始まり毎ターン+1（全員の魔力が20未満）。技5の味方兵が20ターンで払える量は 5+19＝24
  ＝キラー系なら6回・銀なら2回。味方の技は3〜6なので鋼・銀は開始時ほぼ使えない＝**戦いのほとんどは鉄の武器**
- 敵弓兵→味方飛行兵（HP20）は 27（白翼特効）で、移動して撃っても一撃
- 斬馬刀→敵槍騎兵（HP20）は 26 で一撃（三すくみ逆転で不利−2 が有利+2 になる）
- 敵槍騎兵→輸送隊（HP20）は 15（槍の騎馬有効＋非武装扱い）で、2体に殴られると即敗北
- 鋼の「速さ−移動力」は、いまの技・速さ（1桁）では三すくみの補正が最低値2に張り付く場面が多く、効き目は小さい
  （速さが効くのは、攻撃を受けるときの三すくみの補正と、覚醒の貯まり方）

**実装の要点**

- 窓口は `WeaponMemoryRules`（`CanAfford`・`CanEquipByClass`・`PayForAttack`・`AutoSwitchIfUnaffordable`・`FindAutoEquip`）
- **「払えない武器では攻撃できない」は `CombatRules.TryGetAttackRange` の1か所**（射程なしを返す）。
  呼び出し側はすべて攻撃の判定なのでそろう。`Unit.Weapon` は払えない武器もそのまま返す（守りで武器として働かせるため）
- 挟撃の支援役のメモリは `CombatRules.FindPincerAlly` が見る。ガード役（`WouldGuardAt`）は見ない
- 自動の持ち替えは `WeaponChoiceRules.CanChooseWeapon` が false の陣営（＝敵）だけ
- 払い・持ち替えはログを伴う本番の処理なので、戦闘予測や敵AIの見積りからは呼ばない（副作用の無い `CanAfford`・`CostOf`・`MemoryOf` を使う）
- 剣の再移動の判定は、使った武器を**戦闘の前に控えて**決める（敵は払った後に持ち替わるため）
- 敵AIの点数定数は変えていない（敵は平時いつも払える武器を持つので、`Weapon` 窓口・`CanAttack` 経由で自動で追随する）。
  `ThreatMap` の挟撃の脅威は払えるかを見ない＝やや過大な見積り

## 攻撃時の武器選択の合意仕様

攻撃は**武器を選んでから相手を選ぶ**（FE の古典的な流れ。作者が操作順を見直した末の形）。

```
行動メニュー「攻撃」／「必殺技」
  → 【武器選択】ユニットの右隣に武器の一覧（武器1本でも必ず出る）
       ・行にホバー → その武器で狙える敵が盤面で赤く光る
       ・使えない武器は理由付きの灰色行（「（メモリ不足）」「（届く敵なし）」）
       ・行をクリック → その武器を装備して対象選択へ
  → 【対象選択】その武器で攻撃できる敵が赤
       ・敵にホバー → 右上に敵ユニット情報・盤上の隅に戦闘予測
       ・敵をクリック → その場で攻撃 → 行動終了（「実行」の確認は無い）
```

「持ち物」で持ち替えてから攻撃するのと結果は同じだが、メニューを2往復せずに済む＝特効武器の持ち替え忘れを無くすのが目的。

- **武器が1本でも一覧は必ず出す**（作者合意）＝どの武器で戦うのかを毎回目にする形。
  一覧はユニットの右隣（画面の右端では左隣へ回り込む）。行は武器名だけ（装備中の武器には「（装備中）」）
- **武器を選んだ時点で装備が切り替わる**（作者合意・FE準拠）。
  この後キャンセルしても**その武器を装備したまま**（装備変更に取り消しは無い）。
  行動は消費していないので、そのまま別のコマンド（待機・持ち物など）へ進んでよい。
  攻撃の後もその武器のまま＝**敵フェイズもその武器で受ける**（三すくみ・挟撃の資格が変わる）
- **武器の行にホバーすると、その武器で狙える敵を盤面に赤く出す**（作者合意）。
  相手を先に選べないぶんの埋め合わせ。塗り直すのは行が変わったときだけ（IMGUI は毎フレーム呼ばれるため）
- **押せるかどうかは武器ごとに決まる＝その武器で狙える敵が1体でもいるか**（相手はまだ決まっていないため）。
  灰色の理由は「メモリ不足」（必殺技なら1本＋消費で判定）／それ以外は「届く敵なし」
- **「攻撃」コマンドが出る条件＝持っている武器のどれかで届く敵がいるか**（装備中の武器基準ではない。作者合意）。
  移動選択中の赤い攻撃範囲・被ダメ確認の相手も全武器の合算。**敵は装備中の1本だけが候補**
- 候補の武器（`GetAttackWeapons`）: プレイヤーは所持品の武器のうち、杖でなく兵種が扱えるもの
  （メモリ不足も候補＝理由を見せる）。装備中の武器は、兵種が扱えない例外装備でも必ず候補に入れる
- **対象選択中は戦闘予測（盤上の隅）と敵ユニット情報（右上）が同時に出る**（作者合意）。
  戦闘予測の1行目には「武器: 斬馬刀（消費4）」＝いまどの武器で殴ろうとしているかが出る
- **武器の一覧は他のパネルに被らない位置へ逃がす**（作者要望）。避ける相手は戦闘予測とユニット情報の2枚で、
  逃がし方は「反対の隣へ回り込む → それでも重なるなら縦にずらす」（`ItemListMenu.AvoidPanels`）。
  矩形は各パネルが `PanelRect` で公開し（出していなければ Rect.zero＝避ける対象から自然に外れる）、
  `BattleController.AvoidPanelRects` が窓口として渡す。持ち物・交換のメニューは渡していない
- **【重要】逃がす位置を決めるのは一覧を開いた最初の1回だけ。開いているあいだは動かさない**。
  毎フレーム決め直す作りだと武器を選べなくなる。右上のユニット情報パネルは盤面のクリックを独自に拾うので、
  行を押した瞬間に下のマスのユニットが右上に出て（あるいは消えて）パネルの大きさが変わり、
  避ける先が変わって一覧がユニットの左右に飛ぶ → マウスを離したときには行が別の場所にありクリックが不成立、を繰り返すため。
  位置の確定は最初の Repaint まで待つ（`PanelRect` は描いたときの値なので、開いた直後の Layout ではまだ今フレームぶんが入っていない）。
  ずらし量だけを覚えて基準位置には毎フレーム足すので、カメラが動いても追従する
- 必殺技も同じ流れ。**メモリが減るのは敵をクリックした瞬間**＝それまでに右クリック/ESC で戻ればメモリは減らない
  （装備の切り替えだけは武器を選んだ時点で確定する）。キャンセルは1段ずつ＝**対象選択 → 武器選択 → 行動メニュー**
- 判定は `WeaponChoiceRules` に一元化する。**probe（お試し装備）方式**＝一時的にその武器を装備して既存の共有関数を呼び、
  finally で必ず元へ戻す。射程・三すくみ・特効・挟撃・メモリの可否が引数を増やさずに全部その武器の判定になり、
  **表示（狙える敵・戦闘予測）と実戦の結果がズレない**。
  そのため **`Unit.Equip` / `Unequip` には副作用（ログ・演出・行動消費）を足さないこと**（`Unit.cs` に警告コメントあり）
- 杖（回復）の武器選択は無い（杖を2本持つユニットが出たら同じ形で足せる）
- 味方が払えない武器から払える武器へ持ち替えるのは、この武器選択で選んだときだけ
